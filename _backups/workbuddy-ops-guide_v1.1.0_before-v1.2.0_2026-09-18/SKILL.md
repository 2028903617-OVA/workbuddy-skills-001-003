## §0 给使用者的第一条提醒

**给别人 / 别的组织用之前，先跑一遍脱敏自检**（见 §4 V3 与 `scripts/scan_secrets.py`）。
本手册本身已脱敏，但**你在自己环境里补录的速查表、示例、路径，可能带你的主体信息**，补录后要重新自检。

## §1 十条铁律（最高优先级，违反必翻车）

| # | 铁律 | 一句话原因 |
|---|---|---|
| **F1** | **绝不并行 Edit 同一文件** | Edit 是"读→改→写"，同消息多次并行会互相覆盖，**静默丢失且无报错** |
| **F2** | **内容含反引号/特殊字符时，绝不走 shell** | bash 会做命令替换，把 `` `SomeApiName` `` 这类内容直接吞掉 |
| **F3** | **生成的文件必须回读实际产出再交付** | 凭记忆汇报必然出错；docx 用文本 dump，xlsx 用脚本读回 |
| **F4** | **版本迭代另存新名，并显式声明哪一版是最终版** | 同名多版必然误发；`_v2` `_v3` 递增，禁用覆盖 |
| **F5** | **写盘前探测占用，占用则另存** | Office/预览面板锁句柄 → `PermissionError`；不中断，改 `_v2` |
| **F6** | **对外文件先跑脱敏自检，且必须看上下文** | 命中词常在"本件不含…"免责句里，只数词频会误判 |
| **F7** | **读外部导出的 Excel 一律 `read_only=False`** | 导出文件尺寸信息不规范，只读模式会只读到 0~1 行/列 |
| **F8** | **跨机任务第一步先硬件取证确认本机是哪台** | hostname/用户名不可信，猜反则路径、排程、同步全盘做反 |
| **F9** | **不做推测性决策**（样式、口径、命名） | 用户手调版才是权威；口径不明就问，不猜 |
| **F10** | **口径变更要显式收回上一版说法** | 静默改会让用户拿旧说法对新文档，判断依据失效 |

## §2 环境基线（模板 · 按你的机器填写）

- **Python**：用你环境的绝对路径（虚拟环境里含 openpyxl / python-docx 的那个）
- **Node**：同理用受管版本
- **Bash shim 不可用命令**：`rm` `dirname` `cd` `head` `tail` `grep` `ls` → 一律改 Python（报 `command not found` / Exit 127）
- **Glob 可能不认某些盘符** → 用 Python `os.listdir` 写临时文件再 Read
- **Read 单行超长会截断** → 长文本先切分
- **PowerShell 可能不回显 stdout** → 取信息走 Python

## §3 踩坑速查总表（52 条 · 按编号跳详情）

### A 环境与执行（10）
| 编号 | 一句话 | 正确做法 |
|---|---|---|
| A01 | bash shim 缺命令报 not found | 改 Python，勿重试 |
| A02 | **反引号被命令替换吞掉** | 写文件走 Write/Edit/Python |
| A03 | Read 长行截断 | 先切分 |
| A04 | Glob 不认某些盘符 | os.listdir |
| A05 | PowerShell 不回显 | 走 Python |
| A06 | 终端非管理员**静默失败** | 脚本开头自检管理员并报错退出 |
| A07 | ExecutionPolicy Restricted | `-Scope Process Bypass` |
| A08 | 改完 PATH 不生效 | 新开终端/重拼 `$env:Path` |
| A09 | Git Bash 解不了 zip | Python `zipfile` |
| A10 | `pip install -U pip` 被拒 | `python -m pip install` |

### B 文件生成与 Office（14）
| 编号 | 一句话 | 正确做法 |
|---|---|---|
| B01 | 文件被占用 PermissionError | 探测可写性 → 另存 `_v2` |
| B02 | `~$` 锁文件混入遍历 | 过滤 `~$` 前缀 |
| B03 | Office 窗口置顶遮挡 | 用户侧设置关闭，程序无法根治 |
| B04 | 数组公式首字符被吃 | text 必须 `=` 开头 |
| B05 | `read_only=True` 读空 | 改 `read_only=False` |
| B06 | 覆盖写值把样式写丢 | 只改 `cell.value` |
| B07 | 重排行后样式错位 | 按行类型整行刷样式 |
| B08 | 百分比/小数混排 | 生成后按列强制统一 number_format |
| B09 | 硬编码美化被否 | **模板继承法**（见 R02） |
| B10 | `move_sheet(name,0)` 不动 | `wb._sheets.remove` + `insert` |
| B11 | 验证只和上一版比 | 三查：重算/公式/样式 diff |
| B12 | 批量改只改了部分却报全改好 | 逐个核验再汇报 |
| B13 | 样式 diff 取 theme 色错 | 用 `str(cell.fill)` 整体比较 |
| B14 | 公式比易用 `str(cell)` 误报 | 用 `cell.value` / `.text` |
