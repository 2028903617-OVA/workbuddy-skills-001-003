# 录单录入规范与审核流程（欣锋集团 2026.1 版）

> 来源：《纷享销客培训用文稿 2026.1.docx》（演讲逐字稿）+ 《纷享销客录单2026.1.pptx》（操作 SOP 34 页）。
> 全品牌通用；是集团联单 / 西门子 / 欣暖家三大自动化任务的**业务规则源头**。

## 一、录单基本流程（顺序，6 步）

1. **获得客户信息 → 录入销售线索**
   - 当天内完成；四项必填 = 客户姓名、微信号/电话(二选一)、客户来源、有效交互凭证。
2. **线索转换客户**
   - 拿到准确姓名 + 手机 + 家庭地址时，用「转换」建客户；**必须选正确《本人所属品牌》**。
3. **客户下建销售订单**
   - 选业务类型；填必填 + 订单产品；确认带单类型；填预约配送时间（芯猫除外）；**0 元产品标「是否赠品=是」**；不同业务类型不混一张单。
4. **回款**
   - 关联回款明细（可多选），改「本次回款金额」并核对。
   - 定金回款（未产生订单）不绑明细；销售回款（已产生订单）**必须绑明细**。
5. **高级外勤**
   - 客户下发起「客户拜访及服务」→ 选服务主题 → 签到 + 拍门头照片 + 填沟通记录 → 签退（间隔 ≥5 分钟）。
6. **变更/退款**
   - 合同变更单仅 4 类：退货 / 换货（1→多→差额整单退货）/ 单价变更 / 单价金额都减少。
   - 新增产品 = 直接建 0 元赠品订单，**不需变更单**；退款关联回款明细。

## 二、三大录入对象规范 + 审核自查点

| 对象 | 录入要求 | 审核自查点 |
|---|---|---|
| **销售线索** | 真实 / 时效(当天) / 完整(四项必填) | 时效、准确(联系方式有效)、一致(与凭证一致)、完整 |
| **销售记录(跟进)** | 真实 / 阶段标记(需求沟通·方案报价·系统报备等) / 关键信息(需求变化·异议处理) | 真实、阶段准确、关键信息及时完整 |
| **高级外勤** | 定位打卡 / 内容(服务主题+门头照片+沟通记录) / 签退≥5分钟 | 打卡真实、内容完整、签退合理 |

## 三、审核流程与结果

- **时效**：当天 16:00 前录入 → 当天 18:00 前审完；16:00 后录入 → 次日 10:00 前审完。
- **结果**：
  - 通过 → 系统自动积分；
  - 补充完善 → 退回，销售人员 **1 个工作日内**修改重提；
  - 不通过（严重错误/虚假）→ 判无效，不计分。

## 四、积分生成底层逻辑（⚠️ 直接关联西门子/欣暖家反写任务）

- 当天积分在**每晚 24:00** 生成，只统计**审批通过**的考核指标。
- **客户成交状态 = 首次回款单审批通过才反写**；销售订单审批不统计为成交。
- **转正申请**通过 → 生成当月积分+考核金（转正上月不计；实习期需店长+事业部经理确认凭据，人工计算）。
- 常见不计分场景：
  1. 销售记录昨天建但今天未审 → 不计分；
  2. 订单审批 ≠ 成交（见上）；
  3. 审批未通过 → 看 CRM 提醒-审批消息里的驳回原因；
  4. 跟进照片与所选动作不符（如邀约记录传了方案设计图）→ 驳回重传；
  5. 品牌无此得分项，或跟进周期内不允许重复分数 → 先了解本品牌得分项与审批要求。
- 国补订单：一线索一客户，销售订单录到**主客户**，产品明细选对应刷卡人，不允许新建多个线索。

## 五、特别事项 / 易错点

- **重复数据无法新建**：联系线索审单员或走「重复线索/客户申领」→ 成为联合跟进人（场景选「全部」或「我联合跟进的」查找）。请勿改原数据。
- **违规新建重复客户**（改电话）：重点查 **电话 + 本人所属品牌**。
- **撤回审批**：未审完可撤回；审批人员确认后保留 5 分钟内也可自行撤回。
- **0 元产品**必须标「是否赠品=是」。
- **无效线索**须经审单员审批；一直留存会累计超留存上限，导致无法录新线索。
- **方案/设计稿**须体现是哪位客户，或聊天记录中有设计图/报价，否则审核无法判定归属 → 驳回。
- **邀约已到店 = 邀约动作 + 客户进店**两个动作（不便拍客户照时，仅传微信邀约照也可）。
- **日常沟通禁群助手群发**，违者直接驳回。
- 首页可设常用 CRM 模块便于查找/新建；优秀讲解话术公海池可点赞/评论。
