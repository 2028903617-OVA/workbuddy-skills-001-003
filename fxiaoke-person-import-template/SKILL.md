# 纷享销客 人员对象 导入模板生成

## 适用场景
- 用户要把 Excel 考核目标（如月度销售指标）批量导入纷享销客「人员对象」。
- 需要批量更新人员字段（员工状态、各类指标等）。
- 用户导出人员对象后，需要按「更新已有数据」模式回填。

## 权威字段来源（不要再猜，直接用）
1. **官方导入模板**（用户导出的最权威格式）：`人员对象更新导入模板 (2).xlsx`
   - Sheet「人员导入模版」表头即导入列；**必填列**（表头带「必填」字样）：`唯一性ID（必填）`、`考核角色（必填）`、`员工状态（必填）`、`性别（必填）`、`主属部门（必填）`。
   - **主键匹配列 = `唯一性ID（必填）`**（不要依赖系统名做主键）。
   - `月度销售指标` = 金额字段（元，最大14位/2小数）；格式示例「123」。
   - 日期字段格式必须 `2026-8-21`（只有与示例格式一致才生效）。
2. **字段定义备份**：`D:/Backup/Downloads/N_202607_24_7b79918c157c4566bc7eccf498773f0d.xlsx.xlsx` → Sheet「人员(PersonnelObj)」（含字段 ApiName、类型、是否必填）。
3. MCP 读写：fs-server 读接口可用；写接口 `UpdateRecordsByData` 可达（单查询 50 条硬上限见 fxiaoke-sse-client）。

## 数据流与取数
- **考核目标源**：`7月考核金额比对(2).xlsx` → Sheet「目标」：
  - 第 1 行 = 标题，**第 2 行 = 列名**（门店/人员/职位/8月/9月…），**数据从 index 2 起**（跳过两行表头）。
  - 取列：人员 = index 1，职位 = index 2，目标月份金额 = index 4（9月）。
  - **跳过 role（职位）为空的行**（门店合计/分销/总计行，勿当人员）。
- **人员 ID 源**：`人员对象导出结果_*.xlsx` → Sheet「人员数据」：
  - 键值：系统名（昵称）→ 唯一性ID（`唯一性ID（必填）`）。
  - 同时取「员工状态（必填）」备用。

## 核心转换规则（务必遵守，勿靠猜）
1. **金额单位换算**：考核表金额单位是「万元」，导入字段是「元」→ `月度销售指标 = float(万元_raw) * 10000`，建议 `int(round(...))`。
2. **新旧导出口径合并**：不同时点导出的人员文件可能命名被改、口径不同（实测：27364 仅含离职/停用且命名与门店名单对不上，38453 能匹配门店名单但不含离职者）。策略：**在册人员取旧导出 ID，离职/停用人员取新导出 ID 并强制标「停用」**；匹配键一律用「系统名（昵称）→ 唯一性ID」。
3. **员工状态**：离职者 `员工状态 = 停用`；在册者填 `启用`（若导入界面校验必填则填启用，否则留空保持系统原值）。**禁止 rm / 删除个人文件**，扫描=只读。
4. **生成后必须回读核对**：① 匹配人数 == 考核表人员数（无误漏）；② 金额 ×10000 正确；③ 离职者状态码正确；④ 门店合计行未被当成人员。

## 输出模板结构（推荐完整版，一次导入成功）
- 直接取人员导出里系统已有的「考核角色 / 性别 / 主属部门 / 员工状态」真实值回填（导出本身即系统数据，格式必对，不会触发格式报错）。
- Sheet1「导入数据」表头（6 列，对齐官方必填）：`唯一性ID（必填）`、`考核角色（必填）`、`性别（必填）`、`员工状态（必填）`、`主属部门（必填）`、`月度销售指标`。
- Sheet2「匹配对照与说明」：系统名 / 唯一性ID / 考核角色 / 性别 / 员工状态 / 主属部门 / 原值(万元) / 换算后(元) / 匹配状态，便于复核。
- 字段索引（两版导出文件均一致）：唯一性ID=0、系统名=1、考核角色=3、性别=9、员工状态=13、主属部门=37、月度销售指标=65。

## 常见坑（必记）
- 目标 Sheet 有**两行表头**（标题 + 列名），数据从 index 2 起，勿把列名当数据行。
- Bash heredoc 写 Python 时，数字索引极易被模型打成乱码字符（如 `r[第1]`、`trows[, 2:]`）→ **改用 Write 工具写 .py 文件再 execute_command 执行**，避免反复笔误。
- 单 IN 查询上限 50 条（见 fxiaoke-sse-client）；逐人按唯一性ID 匹配优于大 IN。
- 自动化删除只能用 `automation_update(mode="delete")`；禁止 rm / sqlite3。
- 个人文件高危：扫描=只读，删除/移动需备份+确认（见 personal_files_safety）。

- 若导入时报某必填为空，把报错字段名补进模板即可（对照官方模板表头的「必填」列）。
- 本 skill 由实际任务沉淀；如官方模板路径/字段变更，请立即修正本节。
