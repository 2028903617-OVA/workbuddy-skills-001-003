# 能力 2：我方物料匹配外部物料

外部拿来一份物料/型号清单，问「这些在我们系统里对应哪个物料、有没有、销客产品编码是多少」时走这里。

## 我方三张底表

| 底表 | 从哪来 | 关键列 | 用途 |
|---|---|---|---|
| **金蝶物料表**（按组织分文件） | 金蝶导出的 `物料_*.xlsx` | 使用组织 / 编码 / 名称 / 规格型号 / **销客产品编码** | 取销客产品编码；按「使用组织」列可在一张表里区分组织 |
| **产品主数据快照** | `产品对象导出结果_*.xlsx` | 唯一性ID（必填） / 产品名称（必填） / 物料名称 / 型号规格 / 物料编号 | 校验产品是否已同步到纷享销客；**唯一性ID 就是销客产品编码** |
| **价目表明细快照** | `价目表明细对象导出结果_*.xlsx` | 产品（必填） / 价目表（必填） | 判产品是否已进某张价目表 |

一个组织可能有多张物料表（例如一张全量 + 一张彩电专表）。**先读「使用组织」列确认每张表覆盖哪些组织，再决定用哪几张**，不要按文件名猜。

## 铁律：能用「物料名称」列，就绝不用「型号标题」列

实测证据（369 行外部主推货品表 × 销客产品主数据 19222 条）：

| 外部列 | 命中率 | 与我方物料名**完全一致**的行 |
|---|---|---|
| 型号标题（对方自己写的） | 332/369 = 91.2% | **0 条**，全靠模糊包含 |
| 物料名称（仓库） | 94/94 = 100% | 92 |
| 物料名称（组织物料表 A） | 157/158 = 99.4% | 153 |
| 物料名称（组织物料表 B） | 56/56 = 100% | 56 |
| 物料名称（两表合并） | 190/192 = 99.0% | 188 |

**结论**：型号标题与我方物料名零个完全一致，只能靠模糊包含，最容易挂错产品；而「物料名称」类列命中率 99–100% 且几乎全是完全一致。

### 固定匹配顺序（按序短路）

1. **物料名称精确**：外部表里已有的物料名称类列 × 我方底表「名称」/「物料名称」列，**完全相等**
2. **规格型号精确**：外部规格型号列 × 我方「规格型号」，完全相等
3. **型号标题模糊**：仅在前两步全落空时启用，且**每个候选必须过 `fuzzy_ok()` 两道闸**（品牌一致性 + 型号码边界，见 `field-mapping.md`）
4. 全落空 → 进未匹配清单，**再走一遍连接器兜底**（快照滞后 1–3 天是常态，直接判「我们没有」会误报）

## 销客产品编码从哪取（按序回落，取不到就留空）

1. **金蝶物料表**按「物料名称 → 规格型号」查到唯一编码 —— 官方维护的对照关系，最权威
2. 物料表没覆盖该物料 → 用**产品快照的「唯一性ID（必填）」**

第 2 条的实测依据（2026-09-22 用 `物料_2026090811195478_190792.xlsx` × `产品对象导出结果_20260921103358125.xlsx` 逐行交叉验证，1104 行同名可比对）：

| 快照字段 | 与物料表「销客产品编码」完全一致 |
|---|---|
| **唯一性ID（必填）** | **1103 / 1104** ✅ |
| 产品编码 | 0 / 1104（该列大面积为空） |
| 物料编号 | 0 / 1104（**这是 ERP 存货编码**，形如 `03.05.01.02.030`） |

> 🔴 别填错：`产品编码` 和 `物料编号` 都不是销客产品编码，填出去整批数据对不上。

**为什么需要这条回落**：本地金蝶物料表往往比产品快照旧（实测 09-07/09-08 的物料表 vs 09-21 的快照），只认物料表会出现「139 行全匹配上、但编码全是空」的情况。回落时**必须在 `备注` 列写明出处**（`销客产品编码取自产品快照唯一性ID（金蝶物料表未覆盖该物料）`），便于抽查。两个来源都取不到 → 留空 + `待人工确认`，绝不猜。

### 金蝶物料表缺失时怎么办

**降级继续跑**，不要停手：只按产品快照匹配，销客产品编码走唯一性ID 回落，`物料编码` 用快照的「物料编号」（同口径，实测 1103/1104 与物料表「编码」一致）。结果里必须带 `降级说明`，并提醒用户「导入前人工复核」。

只有**物料表与产品快照都没有**时才停止——一个底表都没有，匹配结果就没有依据。


## 列定位：按表头语义找，不按列位

外部表格式每次都可能不一样，**禁止写死列字母**。表头行 = 前 8 行里「命中语义关键词最多」的那一行；数据起始 = 表头行 + 1。

| 语义 | 表头关键词（命中其一即认） | 必需 |
|---|---|---|
| 型号标题 | 型号标题 / 型号 / 商品名称 / 货品名称 / SKU名称 | 三选一即可 |
| 物料名称 | 物料名称 / 产品名称 / 我方名称 / 金蝶名称 | 同上（有则优先用） |
| 规格型号 | 规格型号 / 规格 / 型号码 | 同上 |
| 品牌 | 品牌 / 品牌系 | 否 |
| 行业/品类 | 行业 / 品类 / 大类 / 品项 | 否 |
| 外部编码 | 编码 / SKU ID / 商家编码 / 店铺ID | 否 |

> 🔴 **型号标题不是入场券**：源表只要有「物料名称」或「规格型号」列就能跑，第一级匹配走的就是物料名称。金蝶供货价表（品牌/物料名称/规格型号/供价/核算价/限价/面价/品类）这种**没有型号标题列**的表，必须能进流程——实测 297 行靠物料名称匹配上 262 行 + 规格型号 18 行。只有三类列一个都没有时才停手。

## 输出

`外部物料匹配结果_{组织}_{YYYYMMDD}.xlsx`，三个 sheet：

1. **匹配结果** — 外部原始列 + 追加 10 列：`我方产品名称` / `我方物料名称` / `物料编码` / `规格型号` / `销客产品编码` / `所属组织` / `匹配方式` / `置信度` / `来源` / `备注`
2. **未匹配清单** — 三类原因**分开列**，不要混成一张表：
   - 我方无此物料（金蝶未同步）
   - 存在同名多物料（需人工选，不自动取第一条）
   - 疑似错配（品牌不一致或型号码边界不完整被闸拦下）
3. **统计** — 各匹配方式命中数、未匹配分类计数、所用底表文件名与日期

`匹配方式` 取值只有四种：`物料名称精确` / `规格型号精确` / `型号标题模糊` / `未匹配`。

## 坑（都实测踩过）

- **同名多物料不许自动取第一条**：金蝶物料表里同名记录常见（实测 28 行有 2 条同名，涉及创维、海信、小天鹅）。同名冲突一律进「存在同名多物料」清单交用户选。
- **占位值不是物料名**：外部表里物料名称列的值等于 `0` 或空字符串时，那是「我方没有」的占位，**跳过**，不要拿去匹配。
- **外部表格结构会中途变**：对方加了列以后价格列整体右移是常事。每次跑都要重新按表头定位，**不能沿用上次的列位**。
- **品牌要对齐，不能信外部写法**：外部把 `海信平板电视75D60S` 写成「海尔」，直接信就会挂错。以我方底表的名称/物料名为准，差异写进备注。
- **「金蝶未同步」是结论不是猜测**：必须过连接器确认后才写进未匹配清单。
- **底表可能比产品快照旧**：本地金蝶物料表常滞后（实测物料表 09-07/09-08 vs 产品快照 09-21）。这时编码走快照唯一性ID 回落，并在备注写明出处；别因为物料表里查不到就判「我们没有」。

## 交付话术

报告时给出：匹配上 X 行（各方式分别多少）/ 未匹配 Y 行（三类分别多少）/ 所用底表与日期 / 需要用户决策的同名冲突条数。不要把未匹配行说成「系统里没有」——准确说法是「本次底表里没查到」。
