# 能力 3：外部物料 → 我方内部格式物料名称

对方给的型号是**他们的口径**（电商标题、供应商型号），我方系统要的是**我方口径**。本能力把外部型号翻译成我方内部格式，供「新增产品（金蝶）」和「价目表明细」使用。

## 何时用

| 情形 | 例子 |
|---|---|
| 一次性要进几十/上百个**全新**型号 | 9 月大店货品表 369 个型号，其中 144 个我方系统里没有 |
| 价目表要**大调整**（新建价目表 + 批量铺货） | 新组织第一次铺整表型号 |
| 源表是**对方口径**的型号标题，不是我方口径 | 电商标题：带品牌前缀和营销词 |
| 需要先「新增产品（金蝶）」再「做价目表明细」 | 结果列空白、要生成金蝶物料名 |

**与能力 2 的分工**：能力 2 管「外部物料 ↔ 我方已有物料」的**匹配**；本能力管「我方还没有的型号」的**命名生成**。实际跑批时先走能力 2，剩下的再走本能力。

## 列位：按语义定位，不写死字母

源表格式每次不同，**不要记 F 列 G 列**。开工先做三件事：

1. **读表头**（表头行 = 前 8 行里语义命中最多的一行；有的表 R1 是标题、表头在 R2，也有表头就在 R1）
2. **按语义认列**：

| 语义 | 表头关键词 | 必需 |
|---|---|---|
| 品牌 | 品牌 / 品牌系 | 建议有 |
| 行业/品类 | 行业 / 品类 / 大类 | 用于品项兜底 |
| **型号标题（输入）** | 型号标题 / 型号 / 商品名称 / 货品名称 | ✅ |
| **规格型号（输出）** | 规格型号 / 规格型号（单列） | 有列就写回，没有就追加 |
| **物料名称（输出）** | 物料名称 / 金蝶物料名 / 内部物料名称 | 有列就写回，没有就追加 |

3. **确认输出列**：源表里已经留好的空列（表头写着「规格型号」「物料名称」但整列为空）就写回那些列；没有预留列 → **在末尾追加两列**，列名固定用「规格型号」「物料名称」。

> ⚠️ 对方加列后价格列整体右移是常态（实测出现过 O/P/Q/R → P/Q/R/S）。**每次都要重新定位，不能沿用上次列位。**

## 什么输入不该跑本能力（实测踩过）

**源表只有「物料名称 + 规格型号」、没有型号类列的，不要跑**——那通常已经是**我方口径的规范化内部表**（如金蝶供货价表：品牌 / 物料名称 / 规格型号 / 供价 / 核算价 / 限价 / 面价 / 品类）。这类表的两列本来就是对的，硬跑会：

- 把整串物料名写进「规格型号」列（实测一份 297 行的供货价表，295 行的规格型号被写成物料名）；
- 给本来就正确的物料名再套一个凭样本推断的品项前缀。

碰到这种情况用 `--col-model <列号>` 显式指定解析列才会继续；否则脚本直接停手并提示「若本表已有规范的物料名称/规格型号列，请直接用，不必生成」。

判据一句话：**本能力的输入是对方口径的型号标题清单，不是我方已经规范化的物料清单。**

## 写回铁律：空值不覆盖

生成失败（F/G 为空）时**保留源表原有内容**，不写空值把对的改成错的。生成的原则是补全，不是清场。

## 我方物料名公式

```
我方物料名称 = 品牌（中文）+ 品项 + 规格型号
```

- `容声` + `对开门冰箱` + `BCD-606WKK1FPGZA` → `容声对开门冰箱BCD-606WKK1FPGZA`
- `卡萨帝` + `多开门冰箱` + `BCD-633WLCFDANZCU1 丝绒咖` → `卡萨帝多开门冰箱BCD-633WLCFDANZCU1 丝绒咖`

品牌取**产品实际品牌**（`Ronshen/容声` 取 `/` 后的中文；`TCL` 没有中文名就直接用 `TCL`）。
**永远不要把组织名当品牌**——组织只决定价目表，与物料名无关。

**要保留中文颜色尾缀**（丝绒咖 / 云岩白 / 博卡灰 / 曜金印 / 琥珀钰…）。
历史数据里有漏写的（如 `容声对开门冰箱BCD-606WKK1FPGZA` 少「曜金印」），那是人工疏漏，**不是规范**，照加尾缀。

## 规格型号：从型号标题里提取

规则：**去掉品牌前缀，保留型号码 + 紧随的中文颜色尾缀**，其余营销词删掉。

| 型号标题 | 规格型号 |
|---|---|
| `BCD-515W60FZBAS琥珀钰` | `BCD-515W60FZBAS琥珀钰` |
| `Ronshen/容声 BCD-509P60FZBBX` | `BCD-509P60FZBBX` |
| `Casarte/卡萨帝 BCD-633WLCFDANZCU1 丝绒咖` | `BCD-633WLCFDANZCU1 丝绒咖` |

### 七个必踩的坑

1. **品牌前缀有空格和无空格两种写法**
   `Casarte/卡萨帝 BCD-…`（有空格）和 `SIEMENS/西门子KF88HVA56C湖蕴蓝`（无空格）都要能去掉。
   正则：`^\s*[A-Za-z][A-Za-z\.\-]*/[一-龥]+\s*`
   ⚠️ 不能误伤型号内部的 `/`（如 `H1210-MBLNE/QT98TU1`、`KFR-72LW/U61-1`）——靠「`/` 后面必须紧跟中文」隔开。
2. **电视机型号码可能以数字开头**（`75E8S`、`100L7QR`），正则不能要求首字母。
3. **营销词要清**：`【新品】`、`NN英寸`、`NN吋`、`官方标配`、`大屏护眼`、`世界杯`、`更护眼的家庭影院`、`2026款`、`&nbsp;`。
4. **型号码中间有空格**：`MR- 449WUSJPGZ` → 合成 `MR-449WUSJPGZ`。
   正则必须是 `([A-Za-z]-)\s+(\d)`（**连字符后**才合空格）。写成 `([A-Za-z-])\s+(\d)` 会把 `芙万 Artist 50S` 挤成 `芙万 Artist50S`、`Artist 30 Pro` 挤成 `Artist30 Pro`。
5. **重复片段**：`TINECO/添可 芙万 Artist 50S 芙万 Artist 50S` → 前后半串相同则取一半。
6. **电视的颜色词属于营销词，不是型号尾缀**：`流砂锖`、`枪色`、`钛金灰` 等要删；冰洗的颜色（`丝绒咖`、`云岩白`）**要保留**。差别在于冰洗颜色贴在型号码后，电视颜色在尺寸/营销词之后。
7. **型号里自带品牌名但没有 `/` 分隔符**：`大金FFDP90BA`（品牌列也是「大金」）这种，第 1 条的正则够不着
   （它要求 `英文/中文` 格式），必须按品牌列再剥一次。
   ⚠️ 不剥的话拼装时会以为型号已带品牌而省掉品牌前缀，**把品项顶到最前面**，
   拼出 `内机大金FFDP90BA`（正确是 `大金内机FFDP90BA`）——看起来有内容、顺序却是错的，最难发现。
   剥离时要留一手：去掉后为空就别剥（输入只有「大金」两个字时不能剥成空）。

## 品项推断（本能力最核心的一段）

**不要用「品牌 × 行业众数」做主策略**——实测很多组合占比不足半数：西门子×冰箱 27%、美的×冰箱 38%、小天鹅×洗护 40%、东芝×冰箱 42%。

### 五步法

0. **品牌名单只维护一份**：本能力的品牌表直接复用能力 1 的 `BRAND_KEYWORDS`（取并集），**不要另存一份**。
   此前这里另存了 16 个品牌的清单，漏掉大金等 38 个品牌，后果是产品快照里的大金产品
   （实测 1482 条）**一条都进不了样本库**，大金型号推断不出品项、物料名整列空白且不报错。
   实测修复效果：样本库 5961 → 9453 条，600 条回归里 248 条由空变有值、**0 条恶化**。
1. **建样本库**：把产品主数据 + 已新增的价目表明细里的真实命名，按 `(品牌, 品项, 型号码)` 拆开，得到几千条样本。
2. **同品牌最相近型号**：对新型号码，在同品牌样本里取**最长公共前缀 LCP ≥ 5** 或 **相似度 ≥ 0.75** 的那条，借它的品项。
   - `BCD-515W60FZBAS` → 最近 `BCD-505W60CZBAS` → `多开门冰箱`
3. **行业不符则「丢弃」，不是「降级」**：命中的品项行业 ≠ 源表行业时，**必须把 item / LCP / 相似度一起清空**再走兜底。
   ⚠️ 只把 LCP 归零不够——相似度 ≥0.75 那条分支会照样返回错误品项，而且置信度看起来是 1.0，反而最危险（实测把冰箱品项安到洗护型号上）。
4. **分类特化规则**：
   - 空调：`KFR-(\d+)(GW|LW)` 推 挂机/柜机 + 匹数（26→1匹、35→1.5匹、50→2匹、72→3匹）
   - 电视：含「激光电视」→ 品项 `激光电视`；否则 `平板电视`
   - 厨电：`CXW-` 开头 → 油烟机类；`CS` + 蒸烤 → 嵌入式蒸烤一体机类
5. **兜底行业众数**（**必须排在其他兜底之前**），并用脏值表过滤（含 `IOT` / `智能物联` / `赠品` / `样机` / `空机` 的品项直接丢掉）。
   实测卡萨帝水健康众数取到过 `倍世中央软水机IOT智能物联` 这种脏值。
6. **最后才是行业兜底**：水健康 → `净水机`、热水器 → `燃气热水器`（低置信，必进待确认清单）。
   ⚠️ 顺序不能反：兜底写在众数前面时，本该由众数得到 `前置过滤器` 的行会被 `净水机` 抢先，实测一次退化 6 行。

### 品项清洗

- 去掉尾部尺寸数字：`平板电视75` → `平板电视`（正则 `\d+\s*$`）
- 去掉尾部残留字母：`滚筒洗衣机CE` → `滚筒洗衣机`；`滚筒洗衣机CEC` → `滚筒洗衣机`
  （`CE`/`CZ`/`CG`/`CEC` 是系列前缀，不是品项）⚠️ 正则用 `[A-Z]{2,4}\s*$`，写成 `(CE|CZ|CG)$` 治不了三字母的 `CEC`。
- 脏值被过滤后**要马上兜底**，「过滤 + 兜底」是一体的：清掉 `IOT智能物联` 后若行业是水健康 → `净水机`；清掉 `空机` 后若行业是热水器 → `燃气热水器`。只清不兜底会得到空品项，我方物料名整条空掉。

## 电视机特殊处理

电视的型号标题常是长中文串（`海信RGB激光电视 星光S1纯享版 110英寸 110L7QR 大屏护眼 世界杯 流砂锖`），直接拼会得到 `海信平板电视海信RGB激光电视 星光S1纯享版 …` 这种嵌套重复。

**做法**：电视行不走通用清洗——先删品牌名/营销词/颜色，再抽取型号码（`110L7QR`、`85D50SD`、`75Q8H`）；抽不到型号码就退回清洗后的中文系列名（`星光S1`、`星光S2 纯享版`）。
拼装时**只要规格型号里同时含品牌和品项，就原样返回**（只判断品牌开头仍会拼出 `激光电视海信激光电视星光S1` 这种嵌套）。

**系列后缀要补回**：抽型号码的正则要求「含数字」，会把 `Ultra`/`Pro`/`Max` 这些无数字后缀漏掉，导致 `115Q10M Ultra` 被截成 `115Q10M`。抽完码后看紧跟的词，命中 `Ultra|Pro|Max|Plus|Mini|SE|X` 就拼回去。

结果样例：`海信激光电视110L7QR`、`创维平板电视75Q8H`、`TCL平板电视115Q10M Ultra`。

## 交付物

1. **源表副本**（绝不覆盖原件）：输出两列填好
2. **待确认清单**：低置信行 —— 行号 / 品牌 / 行业 / 规格型号 / 我方物料名 / 品项来源 / 置信度
3. 回到能力 1 生成**新建价目表明细**导入文件（若本次目的是入价目表）

## 校验清单

- [ ] 两个输出列**零空值**（有空值说明清洗规则漏了某种写法）
- [ ] 抽样 10 行人工比对：我方物料名 = 品牌 + 品项 + 规格型号，无嵌套重复
- [ ] 电视行：品牌只出现一次
- [ ] 空调行：匹数 / 挂机柜机 与型号码 `KFR-xxGW/LW` 一致
- [ ] 低置信清单已交付用户复核
