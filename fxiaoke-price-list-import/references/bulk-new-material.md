# 特别分支：批量新增物料（大批量新型号 / 价目表大调整）

## 何时走这个分支

主流程（SKILL.md 主流程 1–8）解决的是「源表型号**已存在于**纷享销客产品主数据」的情形。
出现下面任一情形时，先走本分支，再回到主流程：

| 情形 | 例子 |
|---|---|
| 一次性要进几十/上百个**全新**型号 | 天猫 9 月主推表一次性 369 个型号，其中 144 个销客里没有 |
| 价目表要**大调整**（新建价目表 + 大批量铺货） | 新建「天猫价目表20260901」后整表铺型号 |
| 源表是**对方给的型号**（电商标题口径），不是销客口径 | 天猫/京东主推表，型号带品牌前缀和营销词 |
| 需要先「新增产品（金蝶）」再「做价目表明细」 | F 列空白、需要生成金蝶物料名 |

**分工一句话**：先按本分支把新型号整理出「规格型号 + 金蝶物料名」，再回主流程做价目表明细导入文件。

## 源表列语义（三列核心）

大批量表常见布局（本分支已在实战中验证过的一种）：

| 列 | 含义 | 说明 |
|---|---|---|
| A 品牌 | `Ronshen/容声`、`TCL` | 品牌中文取 `/` 后面部分；**TCL 没有中文名，直接用 TCL** |
| C 行业 | 冰箱 / 洗护 / 电视机 / 厨房大电 / 居家清洁 / 空调 / 热水器 / 水健康 | 用于品项兜底 |
| **E 型号标题** | **对方（电商平台）写的型号** | `Casarte/卡萨帝 BCD-633WLCFDANZCU1 丝绒咖` |
| **F 规格型号（单列）** | 从 E 提取出的**纯规格型号** | `BCD-633WLCFDANZCU1 丝绒咖` |
| **G 物料名称** | 金蝶新建格式 | `卡萨帝多开门冰箱BCD-633WLCFDANZCU1 丝绒咖` |

> ⚠️ 这不是固定布局。不同源表列位会变，**先读表头再定列位**。
> 实战中出现过同一张表加了 F/G 两列后，价格列整体右移 2 位（O/P/Q/R → P/Q/R/S），
> 按旧列位取数会取错。**改表结构后必须重新确认列位。**

## G 列公式（金蝶新建格式）

```
G = 品牌（中文）+ 品项 + 规格型号
```

- `容声` + `对开门冰箱` + `BCD-606WKK1FPGZA` → `容声对开门冰箱BCD-606WKK1FPGZA`
- `卡萨帝` + `多开门冰箱` + `BCD-633WLCFDANZCU1 丝绒咖` → `卡萨帝多开门冰箱BCD-633WLCFDANZCU1 丝绒咖`

**要保留中文颜色尾缀**（丝绒咖 / 云岩白 / 博卡灰 / 曜金印 / 琥珀钰…）。
人工历史数据里有漏写的（如 `容声对开门冰箱BCD-606WKK1FPGZA` 少了"曜金印"），
那是人工疏漏，**不是规范**，照加尾缀即可。

## F 列：从 E 提取规格型号

规则：**去掉品牌前缀，保留型号码 + 紧随的中文颜色尾缀**，其余营销词删掉。

| E | F |
|---|---|
| `BCD-515W60FZBAS琥珀钰` | `BCD-515W60FZBAS琥珀钰` |
| `Ronshen/容声 BCD-509P60FZBBX` | `BCD-509P60FZBBX` |
| `Casarte/卡萨帝 BCD-633WLCFDANZCU1 丝绒咖` | `BCD-633WLCFDANZCU1 丝绒咖` |

### 六个必踩的坑（照抄即可避）

1. **品牌前缀有无空格两种写法**
   `Casarte/卡萨帝 BCD-…`（有空格）和 `SIEMENS/西门子KF88HVA56C湖蕴蓝`（无空格）都要能去掉。
   正则：`^\s*[A-Za-z][A-Za-z\.\-]*/[一-龥]+\s*`
   ⚠️ 不能误伤型号内部的 `/`（如 `H1210-MBLNE/QT98TU1`、`KFR-72LW/U61-1`）——
   靠「`/` 后面必须紧跟中文」这个条件隔开。
2. **电视机型号码可能以数字开头**（`75E8S`、`100L7QR`），正则不能要求首字母。
3. **营销词要清**：`【新品】`、`NN英寸`、`NN吋`、`官方标配`、`大屏护眼`、`世界杯`、
   `更护眼的家庭影院`、`2026款`、`&nbsp;`。
4. **型号码中间有空格**：`MR- 449WUSJPGZ` → 合成 `MR-449WUSJPGZ`。
   ⚠️ 正则必须是 `([A-Za-z]-)\s+(\d)`（**连字符后**才合空格）。
   写成 `([A-Za-z-])\s+(\d)` 会把 `芙万 Artist 50S` 挤成 `芙万 Artist50S`、`Artist 30 Pro` 挤成 `Artist30 Pro`。
5. **重复片段**：`TINECO/添可 芙万 Artist 50S 芙万 Artist 50S` → 前后半串相同则取一半。
6. **电视的颜色词属于营销词，不是型号尾缀**：`流砂锖`、`枪色`、`钛金灰` 等要删；
   冰洗的颜色（`丝绒咖`、`云岩白`）**要保留**。差别在于冰洗颜色贴在型号码后，
   电视颜色在尺寸/营销词之后。

## 品项推断（本分支最核心的一段）

**不要用「品牌 × 行业众数」做主策略**——实测很多组合占比 <50%：
西门子×冰箱 27%、美的×冰箱 38%、小天鹅×洗护 40%、东芝×冰箱 42%。

### 五步法

1. **建样本库**：把销客产品主数据 + 「已新增价目表明细」里的真实命名，
   按 `(品牌, 品项, 型号码)` 拆开（用 `parse_name()`），得到几千条样本。
2. **同品牌最相近型号**：对新型号码，在同品牌样本里取
   **最长公共前缀 LCP ≥ 5** 或 **difflib 相似度 ≥ 0.75** 的那条，借它的品项。
   - `BCD-515W60FZBAS` → 最近 `BCD-505W60CZBAS` → `多开门冰箱`
   - `BCD-633WLCFDANZCU1` → 最近 `BCD-633WDCHU1` → `多开门冰箱`
3. **行业不符则「丢弃」，不是「降级」**：命中的品项行业 ≠ C 列行业时，
   **必须把 item / LCP / 相似度一起清空**，再走兜底。
   ⚠️ 只把 LCP 归零是不够的——相似度 ≥0.75 那条分支会照样返回这个错误品项，
   而且置信度看起来是 1.0，反而最危险（实测把冰箱品项安到了洗护型号上）。
4. **分类特化规则**：
   - 空调：`KFR-(\d+)(GW|LW)` 推 挂机/柜机 + 匹数
     （26→1匹、35→1.5匹、50→2匹、72→3匹）
   - 电视：含「激光电视」→ 品项 `激光电视`；否则 `平板电视`
   - 西门子厨电：`CXW-` 开头 → `国产欧式油烟机`；`CS` + 蒸烤 → `国产嵌入式蒸烤一体机`
5. **兜底行业众数**（**优先于行业兜底**），并用 `BAD_ITEM` 过滤脏值
   （含 `IOT` / `赠品` / `样机` / `空机` 的品项直接丢掉）。
   实战中卡萨帝水健康众数取到过 `倍世中央软水机IOT智能物联` 这种脏值。
6. **最后才是行业兜底**：水健康 → `净水机`、热水器 → `燃气热水器`（置信 0.3，必进待确认清单）。
   ⚠️ 顺序不能反：兜底写在众数前面时，海尔 `HKC3000-R988HU1` 这类本可由众数得到
   `前置过滤器` 的行会被 `净水机` 抢先，实测一次退化 6 行。

### 品项清洗

- 去掉尾部尺寸数字：`平板电视75` → `平板电视`（正则 `re.sub(r"\d+\s*$", "", item)`）
- 去掉尾部残留字母：`滚筒洗衣机CE` → `滚筒洗衣机`；`滚筒洗衣机CEC` → `滚筒洗衣机`
  （`CE` / `CZ` / `CG` / `CEC` 是卡萨帝系列前缀，不是品项）
  ⚠️ 正则用 `[A-Z]{2,4}\s*$`（2–4 个大写字母），写成 `(CE|CZ|CG)$` 治不了 `CEC` 三个字母的。
- 脏值被过滤后**要马上兜底**，`fix_item()` 里「过滤」和「兜底」是一体的：
  清掉 `IOT智能物联` 后若行业是水健康 → `净水机`；清掉 `空机` 后行业是热水器 → `燃气热水器`。
  只清不兜底会得到空品项，G 列直接空掉。

## 电视机的特殊处理

电视 E 列常常是长中文串（`海信RGB激光电视 星光S1纯享版 110英寸 110L7QR 大屏护眼 世界杯 流砂锖`），
直接拼 G 会得到 `海信平板电视海信RGB激光电视 星光S1纯享版 …` 这种嵌套重复。

**做法**：电视行不用 F 的通用清洗，走 `tv_model()`——
先删品牌名/营销词/颜色，再抽取型号码（`110L7QR`、`85D50SD`、`75Q8H`）；
抽不到型号码就退回清洗后的中文系列名（`星光S1`、`星光S2 纯享版`）。
拼 G 时**只要 spec 里同时含品牌和品项，就原样返回 spec**（只判断品牌开头仍会拼出
`激光电视海信激光电视星光S1` 这种嵌套）。

**系列后缀要补回**：抽型号码的正则要求「含数字」，会把 `Ultra` / `Pro` / `Max` 这些
无数字的系列后缀漏掉，导致 `115Q10M Ultra` 被截成 `115Q10M`。
抽完码后看它后面紧跟的词，命中 `SERIES_WORD`（Ultra|Pro|Max|Plus|Mini|SE|X）就拼回去。

结果样例：`海信激光电视110L7QR`、`创维平板电视75Q8H`、`TCL平板电视115Q10M Ultra`。

## 交付物

1. **源表副本**（不覆盖原件）：F / G 两列填好
2. **待确认清单**：低置信（<0.7）的行，列出行号 / 品牌 / 行业 / F / G / 品项来源 / 置信度
3. 回到主流程生成的**新建价目表明细**导入文件

## 校验清单

- [ ] F / G 两列**零空值**（有空值说明清洗规则漏了某种写法）
- [ ] 抽样 10 行人工比对：G 是否 = 品牌 + 品项 + F，无嵌套重复
- [ ] 电视行：G 里品牌只出现一次
- [ ] 空调行：匹数 / 挂机柜机 与型号码 `KFR-xxGW/LW` 一致
- [ ] 低置信清单已交付给用户复核

## 实战结论：产品大类 / 产品品项通常留空

做价目表明细时，先查明细快照里同类产品的大类/品项怎么填。
实测 3783 条明细里，含「冰箱」250 条、「洗衣机」222 条、「电视」964 条，
**大类/品项几乎全部为空**。所以没有明确依据时**留空**，不要硬填——
填了不存在的选项会让导入失败。
