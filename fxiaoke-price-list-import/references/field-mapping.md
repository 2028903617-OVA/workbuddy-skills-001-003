## 产品匹配两道闸（模糊路径必过）

「精确 → 型号包含 → 子串」里的**型号包含、子串**两条模糊路径，每条候选都要过 `fuzzy_ok()` 才算命中，否则跳过该候选继续找：

1. **品牌一致性闸**：源表型号与候选产品名各自提取品牌词（内置 30 个品牌词表），两边都提取得到且交集为空 → 拒绝。
   实战案例：`东芝平板电视100Z600QFR-S`（东芝）曾被「型号包含」匹配到 `索尼平板电视100Z600QF`（索尼）。
2. **型号码边界闸**：候选产品名必须含型号码（无型号码的泛化名如「波轮洗衣机」不得作为命中）；候选的每个型号码 token 必须出现在源表型号中，且**紧邻字符不得是字母/数字/连字符/罗马数字**。
   实战案例：`美的电饭煲MB-AFB40C8`（新品）与 `美的电饭煲AFB40C8`（并存老产品）靠 `MB-` 前缀区分，`AFB40C8` 前面贴着 `-` 就说明边界不完整。
3. **括号变体闸**：源表型号含 `(...)` 而候选名没有相同括号段（反之亦然）→ 拒绝（如 `F60-33Q7Pro(HE)` 与 `F60-33Q7Pro` 物料号不同，是两个产品）。

被闸拦下的候选不算命中，继续尝试下一个候选；全部落空 → 进核对清单，走 SKILL.md 的连接器兜底流程。

## 数据 sheet 定位

**多 sheet 累积表（欣暖家年度申请簿等）：只取最新日期的那一个 sheet 处理，绝不把全部 sheet 合并跑**——历史 sheet 的申请早已导入，全量跑只会产出大批无意义的「更新」行。这一条是用户明确的固定口径。

定位方法：倒序（最右优先）遍历 sheet 名，跳过 hidden 开头的表与名为 Sheet1 的表，取第一个首格有值的表。日期名 sheet（如 0326、260910）按时间先后从左到右追加，最右即最新；不解析日期名本身（4 位日期名无年份信息，跨年文件会排错）。

| 列 | 填法 |
|---|---|

| 销售结算价 | 源表结算价（数字） |
| 品牌负责人审核价 | 源表限价（数字） |

| 产品品项 | 按下方品牌特例 |

| 价目表折扣（%） | 恒填 100 |

## 品牌特例

> 下面各节标题里的名字指的是**组织**（决定价目表 + 决定分类怎么填），
> 不是产品品牌。分类特例按组织判断，与「品牌」列各填各的。
> 例：组织=乾鑫 → 分类读源表列，但品牌列仍逐行填 美的/大金/格力 等实际品牌。

### 西门子（交叉填法）
字段名与内容反着填：
- 产品大类列 ← 填【西门子品项】组的值，如 `微蒸烤【西门子品项】`
- 产品品项列 ← 填【西门子大类】组的值，如 `微蒸烤箱【西门子大类】`
- 两组选项清单见 brand-pricebooks.md；用关键词表匹配，匹配不上留空进核对清单。

### 乾鑫
- 产品大类、产品品项直接读源表已有列值，脚本仅校验非空。
- 品牌按源表「品牌」列逐行取（格力 / 大金等），不用整表统一品牌。

### 大金
- 产品大类、产品品项固定填「空调」。

### 欣暖家
- 产品大类、产品品项留空（选项无对应则不硬凑）。

### 启欣
- 4 个价格列（成本价 / 销售结算价 / 品牌负责人审核价 / 价目表售价）留空。
- 产品品项留空。
- 其余列（品牌 / 产品大类 / 产品等级 / 折扣 / 产品 / 价目表 / 业务类型）照常填。
