## 三、子文件拆分与命名

按 (公司, 负责人主属部门) 分组，合并同名子文件。命名函数 `get_subfile_name`：

1. 取付款公司提取后缀：
   - 含"乾鑫" → `乾鑫`
   - 含"智好" → `智好`
   - 含"智德" → `智德`
   - 含"欣锋"/"欣锋控股" → `欣锋`
   - 含"启欣" → `启欣`
   - 否则 → 公司名
2. 若 公司名 ∈ 后缀 或 后缀 ∈ 公司名 → 文件名 = 公司名（如 `乾鑫`、`启欣`）
   否则 → `公司（后缀）`（如 `方太（欣锋）`、`西门子（智好）`）

示例（文件名均带周标签前缀 `集团联单明细2026.07.06-07.12 - `）：
- `乾鑫.xlsx`、`启欣.xlsx`、`欣暖家.xlsx`
- `方太（欣锋）.xlsx`、`西门子（智好）.xlsx`、`西门子（智德）.xlsx`

### 子文件内部小计规则

- **多部门**子文件：按负责人主属部门分组，每组数据后插入"XX部门 小计"行（对金额列求和，提成系数列不求和），最后一行"合计"（汇总各小计）。小计、合计行 **仅 L 列（现场管理/带单费）标黄**，其余列只加粗。
- **单部门**子文件：仅末尾"合计"行（同样仅 L 列标黄）。

## 五之二、数据清洗规则（生成报表前执行，顺序固定）

### 1. 剔除不统计品牌（先执行）

`内部员工主属品牌` 列命中 `BRAND_EXCLUDE`（当前 `['泽锋']`）的**整行删除**，不参与重算、排序、汇总、子文件与任何 Sheet。

注意与"品牌 Sheet 归类依据"区分：归类看**公司**列，剔除看**内部员工主属品牌**列，两列互不替代。

### 2. 带单费为 0 按一个点重算（后执行）

`公司` 列命中 `ZERO_FEE_RECALC_COMPANIES`（当前 `['欣暖家']`）且 `现场管理/带单费` 恰为 0 的行：

```
现场管理/带单费 = round(销售订单金额(元) × 0.01, 2)
内部员工带单提成系数 = 0.01
```

- 系数列同步改写，两列保持一致。
- **仅欣暖家适用**；其他公司的 0 值保持原样，不做任何重算。
- 订单金额无法解析时跳过并打印告警，不写入 0。
- 被第 1 条剔除的行不参与重算。

示例：订单金额 2470 → 带单费 24.70。

### 3. 待回款未收齐 → 暂不计提带单费（全公司适用）

`待回款金额新` ≠ 0（四舍五入到分后非 0）的行：

```
现场管理/带单费 = 0
带单费状态 = 待回款未收齐
```

- 原带单费另存，供"款收齐后补算"。
- 全部公司适用，不分公司、不排除大金。
- 逐条打印 + 汇总进《暂缓带单费清单》。

### 4. 拆单合并看合计毛利 → 带单费封顶（当前限西门子）

分组键 = `公司` + `客户名称` + `客户电话`；组内按**订单日期**（取 `销售订单编号` 前 10 位，回退 `确认时间`）排序，相邻订单日期相差 **> `MERGE_WINDOW_DAYS`（7）天** 即切成两组。

对每一组，取组内 `毛利合计`（第 22 列）之和与当前 `现场管理/带单费` 之和比较：

| 条件 | 处理 | 状态值 |
|------|------|--------|
| 合计毛利 ≤ 0 | 组内带单费全部置 0 | `毛利≤0不发带单费` |
| 0 < 合计毛利 < 合计带单费 | 按原带单费比例分摊，总额 = 合计毛利（末行兜差） | `毛利不足已裁剪` |
| 合计毛利 ≥ 合计带单费 | 不变 | — |

- 单张订单也参与判定（组内仅它自己）。
- 只对 `SPLIT_MERGE_COMPANIES`（当前 `['西门子']`）生效；其他公司不裁剪。
- 组内若已有被第 3 条置 0 的行，不参与分摊基数，其状态保留 `待回款未收齐`。
- 调整明细进《毛利封顶调整清单》。

### 执行顺序（不可调换）

```
剔除不统计品牌(1) → 欣暖家0值重算(2) → 待回款暂缓(3) → 拆单毛利封顶(4) → 排序 → 汇总
```

先算应得、再判暂缓、最后按毛利封顶。顺序错了封顶基数会偏。

## 六、格式规范

- 表头：蓝底白字加粗（填充 `4472C4`），居中。
- 数据行：常规字体（Arial 10），薄框线，垂直居中，自动列宽（上限 40）。
- 汇总/小计行：加粗字体；**仅 L 列（现场管理/带单费）填黄 `FFFF00`**。
- 本期被调整过带单费的数据行（暂缓/毛利封顶）：**L 列填橙 `FFC000`**，与小计合计行的黄底区分开。
- 金额列：`#,##0.00` 千分位格式。
- 启停：本技能目录 `scripts/generate_report.py` 使用 pandas + openpyxl。
