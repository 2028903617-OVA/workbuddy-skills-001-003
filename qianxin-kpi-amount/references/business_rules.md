# 乾鑫 月度考核金额 业务规则与格式规范（v2.0 通用版）

> v2.0 把所有「8 月专用」的写死值改为**按月份 / 按 F2 自动推导**。换月原则上不改脚本。

## 一、输入清单

| 文件 | 含义 | 用途 |
|---|---|---|
| `F1` | 上期「考核金额表」 | ① 目标表基准（五个月目标 / 门店短码 / 分销行）；② 人员表补齐池 |
| `F2` | 本月基础表 | 「个人考核指标达成率（表格）」导出，14 列；**分组、角色、实际值全部来自它** |
| `F3` | 本月人员导出 | 「人员对象导出结果」；人员表主数据 |
| `V2` | 样式模板 | 权威美化版；不传则找 `乾鑫{月}月考核金额表_美化版.xlsx`，再退回 `F1` |
| 补充人员表 | 本月导出漏掉的在册人员 | 可多个；按姓名自动补齐（如调岗被还原的人员） |

> ★ **各版本人员表列数/列序不同**（例：F1 的「人员」sheet 比 F3 少 2 列，且列名是「主属部门」而非「主属部门（必填）」）。
> 补齐时必须**按列名映射**读，绝不能按位置读，否则整行错位。

## 二、四 sheet 结构

1. **新绩效**：人员行（按门店分组）+ 门店小计行 + 合计行。列布局：

| 列 | 内容 | | 列 | 内容 |
|---|---|---|---|---|
| A | 部门 | | M / N / O | 新建线索数指标 / 实际 / 达成率 |
| B | 考核角色 | | P / Q | 第一成交达成金 / 权重 |
| C | 员工姓名 | | R / S / T | 第一成交率指标 / 顾客数 / 达成率 |
| D | 考核金额 | | U / V | ABC成交达成金 / 权重 |
| E | 基础奖金 | | W / X / Y | ABC转化率指标 / 顾客数 / 转化率 |
| F / G | 任务达成金 / 权重 | | **AB:AE** | 阈值表（R36 起，按角色名逐行） |
| H / I / J | 月度销售指标 / 含变更金额 / 达成率 | | | |
| K / L | 线索达成金额 / 权重 | | | |

2. **基数表**：整表嵌套 `F2` 的值（绩效表 `LOOKUP(基数表!C:C=姓名, 基数表!F:F)` 取「含变更金额」）。
3. **人员**：A = 负责人所在部门（`={部门列}{行}`，列号动态，**不写死 U**）、B = 查看绩效表是否为空、C 起 = `F3` 原列。
4. **目标**：门店短码 / 人员 / 职位 / 8月D–12月H / 合计I / 总计J；停用人员姓名带 `(已停用)` 后缀。

## 三、角色规则（`ROLE_RULES`，按 F2「考核角色」列取值）

| 角色 | 基础奖金 base | 阈值档 tier | 个人考核金清零 zero | 引用门店小计 ref_store |
|---|---|---|---|---|
| 销售顾问 | 1000 | 销售顾问 | 否 | 否 |
| 客户经理 | 1000 | 客户经理 | 否 | 否 |
| 店长 | 2000 | 店长 | 否 | **是** |
| 带教导师 | 1000 | **销售顾问** | **是** | 否 |

> - 「带教导师」口径（2026-09 用户确认）：**不计个人考核金（D=0），但团队数据仍计入门店小计**。
> - 门店小计行基础奖金固定 2000。
> - ★ 出现 `ROLE_RULES` 未登记的角色 → 脚本**报错退出**，不猜。

## 四、阈值表（AB:AE，R36 起）

| 档位 | 新建线索数指标 M | 第一成交率指标 R | ABC转化率指标 W |
|---|---|---|---|
| 销售顾问 | 45 | 0.30 | 0.30 |
| 客户经理 | 35 | 0.15 | 0.15 |
| 店长 | 15 | 0.15 | 0.15 |

- ★ **按「角色名」逐行生成**（不是按档位去重）：M/R/W 是 `LOOKUP(1,0/(AB:AB=B{r}), AC/AD/AE)` 按**角色名**查的，
  所以「带教导师」必须有自己的一行（值取销售顾问档），否则取到 `#N/A`。
- 行的先后顺序 = `ROLE_RULES` 的声明顺序（现为 销售顾问 → 客户经理 → 店长 → 带教导师）。
- 门店小计行的 R / W 用**字面值 0.15**（模板惯例）。

## 五、F/K/P/U 四项达成金口径（关键）

| 角色 | F 任务达成金 | K 线索达成金额 | P 第一成交达成金额 | U ABC成交达成金额 |
|---|---|---|---|---|
| **店长** | `=F{小计行}` | `=K{小计行}` | `=P{小计行}` | `=U{小计行}` |
| **其他个人** | `=IF(J>=0.7,IF(J>=1,G,J*G),0)` | `=IF(O>=1,L,0)` | `=IF(T>=R,Q,0)` | `=IF(Y>=W,V,0)` |
| **门店小计** | 同「其他个人」公式，E=2000 | 同左 | 同左 | 同左 |

- 店长按「门店整体达成率」，引用门店小计行；个人按「个人达成率」自算。
- 权重列：`G=E*0.4`、`L=Q=V=E*0.2`。
- **清零角色**（带教导师）：D 列直接写数字 `0`（F/K/P/U 仍按公式算，用于门店小计）。

## 六、ArrayFormula 等号坑（必读）

- 跨表 `LOOKUP(1,0/(...))` 必须写成 `ArrayFormula(ref, "=LOOKUP(...)")`，公式字符串**必须以 `=` 开头**。
- 否则 openpyxl 会吃掉首字母 `=`，单元格显示 `OOKUP...` 公式失效。
- 自检：生成后扫描全部 `ArrayFormula`，确认 `text.startswith("=")` 且数量符合预期。

## 七、样式继承机制（自动，不再逐月手配）

**扫描 `V2` 的「新绩效」建立样式库**：

- **高亮行**：B 列有底色的行 → 记下 `名称 → (theme, tint)`（名称 = 人员姓名，小计行则是门店全名）。
- **停用行**：C 列底色为红 `FFFF0000` 的行。
- **普通人员行 / 普通小计行**：无底色的第一个人员行 / 小计行。

**套用规则**：

1. 人员行：同名 → 用名字对应的高亮色；名字带 `(已停用)` → 用停用样式；否则普通行。
2. **门店小计行：底色 = 本店店长的底色**（`SUB_INHERIT_CAPTAIN_COLOR`）。无店长 → 无底色。
   - 这样「8 月红星店（店长方大露）是绿的 → 9 月方大露调到华东，绿跟着到华东店，红星店恢复无色」自动成立。
3. 合计行：继承**最后一个门店小计行**（动态，不写死 R27）的样式，再**去除底色**。
4. 高亮铺色范围：**A..Y 连续**（模板里历史上有 I 列断开的瑕疵，脚本统一刷满）。
5. 模板里没有的新人/新门店 → 用 `EXTRA_HIGHLIGHT` / `--highlight` 指定颜色。

## 八、数字格式

**模板各行格式并不齐**（例：滨江小计行的 K 列是 `General`，会显示成 `400` 而不是 `400.00`），
脚本在生成后对**表格区（第 2 行 ~ 合计行）**按列统一：

| 列 | 格式 |
|---|---|
| D 考核金额 / F 任务达成金 / I 含变更金额 / K 线索达成金 / P 第一成交达成金 / U ABC成交达成金 | `0.00_ ` |
| H 月度销售指标 | `0.00` |
| J 达成率 / O 达成率 / R 第一成交率指标 / T 第一成交率 / W ABC转化率指标 / Y ABC转化率 | `0.00%` |

其他列（A/B/C/E/G/L/M/N/Q/S/V/X 等）保持模板原样（多为 `General`）。

## 九、已停用标识

继承 `V2` 模板：新绩效已停用人员 **C 列（姓名）红底 `FFFF0000` + 黑字**；基数表/人员/目标保持模板原有样式。

## 十、换月操作 SOP

1. 备好三件套（上期考核金额表 / 本月基础表 / 本月人员导出）。
2. 打开本月基础表，确认列头还是那 14 列、且**含停用人员**（停用人员也在这张表里）。
3. 判断本月是否有：
   - **新人** → 准备 `--new-target`；
   - **人员导出漏掉的在册人员** → 把上月人员表作为「补充人员表」参数传入；
   - **新角色** → 先在脚本顶部 `ROLE_RULES` 登记 + 配 `THRESHOLD_TIERS`。
4. 跑脚本（样式模板传上月成品即可，因为上月成品已含本月要继承的颜色）。
5. 用 Excel/WPS 打开生成的表**重算一次**，按 SKILL.md 的 Verification Checklist 核对。
6. 人工在成品上做视觉微调（如给新店长补色），**下月就把它当样式模板**，颜色自动延续。

## 十一、v1 → v2 改造说明 与 9 月回归结论

### 改造项（v1 的 12 处写死 → v2 自动/可配）

| # | v1 位置 | v1 问题 | v2 做法 |
|---|---|---|---|
| 1 | `ci(F2_HDR,"主属部门-3")` | 9/10 月表头改名 → `KeyError` | 候选列表容错；该列本未被使用 |
| 2 | `range(2,39)` 清行 | 行数写死 | 动态 `ws.max_row` |
| 3 | 合计行样式取 `cell(27,c)` | 写死 R27 | 动态取最后一个门店小计行 |
| 4 | `目标!D:D` | 目标列写死 8 月 | 月份 → 列映射，可 `--target-col` |
| 5 | 角色仅「店长/其他」两档 | 新角色无法表达 | `ROLE_RULES` 四维规则 |
| 6 | 阈值表只 3 行 | 缺「带教导师」→ `#N/A` | 按实际角色名逐行生成 |
| 7 | 人员表只补 `STOPPED` | 补不了在册遗漏人员 | 按 `F2` 名册自动补齐，多池回退 |
| 8 | 目标表只改名 | 成员变动无法重排 | 按新分组重建（保留上期店内次序） |
| 9 | 人员表 A 列写死 `=U{rr}` | `U_COL` 算了却没用 | 动态列号 |
| 10 | 过滤只排 `""/"总计"` | 把「小计」行当人 | 加 `小计/合计` |
| 11 | 参数默认值全写死 8 月 | 不带参跑出 8 月 | 必填 + `--` 覆盖项 |
| 12 | 无样式快照 | 源行号与输出行重叠 → 高亮丢失 | 先 `copy.copy(_style)` 快照再套用 |
| 13 | 手写 `GROUPS` | 换月必改 | 从 `F2` 部门列自动分组 |
| 14 | 补齐按位置读池表 | F1/F3 列数差 2 → 整行错位 | 一律**按列名映射** |
