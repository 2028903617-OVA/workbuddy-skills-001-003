# RAG Search Tool

知识库检索（RAG），从知识库和问答对中检索相关内容。

## How It Works

```text
┌──────────────────────────────────────────┐
│ RAG 知识库检索                             │
├──────────────────────────────────────────┤
│ 用户原问题检索 → 判断结果 → 必要时同义词扩展 │
└──────────────────────────────────────────┘
```

## 检索顺序

固定执行以下分支，不得先改写问题或直接并发扩展查询：

| 阶段 | 判断/动作 | 下一步 |
|---|---|---|
| 1. 原始查询 | 保留用户原始问题，不改写、不删减，执行且仅执行一次知识库检索 | 查询完成后进入阶段 2 |
| 2. 结果判断 | 返回非空结果 | 直接进入结果处理，不做同义词扩展 |
| 2. 结果判断 | 返回空结果 | 进入阶段 3 |
| 3. 扩展查询 | 拆解同义词和关键词后检索 | 与原始结果合并去重，再进入结果处理 |

阶段 1 的查询命令：

   ```bash
   sharecrm knowledge expertise rag-search-knowledge --data '{"content": "<用户原始问题>"}'
   ```

原始查询返回非空数据后，直接进入结果处理，不要为了增加召回数量再次执行同义词搜索。

原始查询返回空结果后，再进入“查询改写”，拆解同义词和关键词并发检索；保留原始查询结果，与扩展结果合并去重。

## 查询改写

将用户口语化查询改写为多个检索词，覆盖关键同义词和常见表述变体。例如：
- "重要客户怎么接待" → `重要客户 接待流程 招待标准`、`VIP客户 来访 接待规范`、`大客户 商务接待 注意事项`


## 请求

仅在原始问题检索返回空结果时，用多个同义词/关键词发起扩展搜索，合并去重结果。score 仅作参考，需自行判断内容是否真正能回答用户问题。

```bash
sharecrm knowledge expertise rag-search-knowledge --data '{"content": "<检索词1>"}'
sharecrm knowledge expertise rag-search-knowledge --data '{"content": "<检索词2>"}'
```

## 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| content | String | 查询词/问题（必填） |

## 结果处理

### QuestionAnswerPairObj 特殊处理

当返回结果中包含 `objectApiName` 为 `QuestionAnswerPairObj` 的条目时，这些条目代表已沉淀的高置信问答对，按以下规则处理：

- **总结**：直接使用该条目的 `content` 字段作为回答内容，不需要二次总结或改写。有 `url` 时，正文中使用 `<sup><a href="url" title="标题" target="_blank"><b>[N]</b></a></sup>` 标注来源。
- **参考资料**：使用 `title` + `url`（如果有 `url` 字段）作为参考链接，按统一编号规则标注来源编号（如 `[N] [title](url)`）。没有 `url` 则只展示 `title`。
- **与其他结果合并**：如果同时返回了 `ServiceKnowledgeObj` 等其他类型的结果，`QuestionAnswerPairObj` 的 content 作为主要回答（总结），其他结果的 title+url 合并到参考资料列表中，统一编号。
