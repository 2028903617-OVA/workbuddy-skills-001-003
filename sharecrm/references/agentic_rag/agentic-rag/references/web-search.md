# Web Search Tool

网络搜索，获取最新信息或公开数据。

## How It Works

```text
┌──────────────────────────────────────────┐
│ Web 网络搜索                               │
├──────────────────────────────────────────┤
│ 直接用 Thought 中"缺什么"作为查询词         │
└──────────────────────────────────────────┘
```

## 请求

```bash
sharecrm knowledge search WebSearchAction --data '{"query":"<Thought 中缺的具体信息>"}'
```

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| query | String | 搜索查询词（必填） |
