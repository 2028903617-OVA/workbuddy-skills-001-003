# 客户产业链位置判断规则

本文定义如何判断目标客户的产业链位置和价值角色。

## 1. 位置判断

围绕以下问题判断：

- 客户是上游、中游还是下游主体。
- 客户更像平台、渠道、服务商、集成商、品牌方还是终端供给方。
- 客户的主要收入和交付链条落在哪一段。

## 2. 输入依据

可使用：

- 主营业务
- 产品和服务
- 目标客户类型
- 销售模式和交付模式
- 官网、年报、公告、新闻中的业务描述

## 3. 输出要求

至少输出：

- 所处环节
- 价值角色
- 主营业务摘要
- 业务含义

## 4. 业务含义

位置判断必须落到客户理解：

- 为什么这个位置会决定客户依赖哪些资源。
- 为什么这个位置会决定客户卖给谁。
- 为什么这个位置会影响客户组织复杂度、采购模式或合作关系。

## 5. 禁止写法

- 只写“中游企业”“制造业企业”这种空泛标签。
- 不解释客户所处环节对经营意味着什么。
