# 产业链结构规则

本文定义 `account-chain-analysis` 如何判断产业链结构和价值流向。

## 1. 先判断结构，再判断关系

先回答：

- 这个行业或业务的价值流向是什么。
- 目标客户位于价值流中的哪一段。
- 该段通常和哪些上游、下游、渠道或生态角色发生关系。

不要先堆关系对象再反推产业链。

## 2. 结构要素

至少识别：

- 上游环节
- 中游环节
- 下游环节
- 价值流向
- 典型玩家类型

## 3. 证据来源

可使用：

- 官网和年报中的主营业务描述
- 行业模板
- 企业公开业务资料
- 公开合作或客户资料

无充分证据时，标注“结构信息有限”。

## 4. 方法论

可按客户所属行业或业务模式选择合适的结构判断方法，例如：

- 技术栈分层
- 供应链追溯
- 渠道分销链
- 服务链

方法论是内部判断工具，不必在正文中机械展开，只需帮助解释客户位置和关系结构。
