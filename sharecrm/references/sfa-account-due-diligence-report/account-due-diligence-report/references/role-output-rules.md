# 角色输出规则

同一份客户尽调报告根据用户角色调整摘要重点和章节权重，不改变事实口径。

## 默认规则

- 无法识别角色时，默认按一线销售视角输出。
- 用户指定多个角色时，优先满足用户明确角色，再保留通用客户理解。
- 不同角色只影响报告裁剪和表达重点，不允许改变事实或编造角色专属信息。
- 同一事实在不同角色下可以调整解释重点，但不能改变事实口径。

## 角色重点

| 角色 | 输出重点 |
|:---|:---|
| 一线销售 | 客户是谁、做什么、当前业务重点、机会信号、合作/竞品信息 |
| 销售管理者 | 客户价值、行业位置、资源投入参考、风险、区域/行业机会 |
| 售前/解决方案 | 主营业务、业务流程、系统相关信号、产业链复杂度、场景复杂度 |
| 客户成功/续费 | 经营压力、历史合作、扩容/续费相关背景、风险变化 |
| 风控/签约 | 主体、股权、司法风险、经营异常、账期和签约风险 |

## 角色裁剪矩阵

| 角色 | 必须强化 | 可弱化 | 禁止倾向 |
|:---|:---|:---|:---|
| 一线销售 | 客户是谁、客户做什么、当前业务重点、合作关系、供应商/竞品、相关情报信号 | 过深行业宏观、过细财务指标 | 直接输出话术、触达路径、跟进计划 |
| 销售管理者 | 客户价值、行业位置、区域/行业机会、资源投入风险、内部覆盖状态 | 日常跟进细节、联系人细节 | 把报告写成个人销售行动清单 |
| 售前/解决方案 | 主营业务、业务流程、系统线索、组织复杂度、项目制/交付复杂度 | 泛泛客户背景、宏观行业铺陈 | 未经证据直接判断客户系统需求 |
| 客户成功/续费 | 历史合作、合同/订单、回款、经营压力、扩容/续费背景、风险变化 | 新客开发信号、陌生客户切入 | 直接输出续费策略或谈判方案 |
| 风控/签约 | 主体有效性、股权关系、司法风险、经营异常、税务、破产、账期和签约风险 | 机会信号、业务切入、供应商关系 | 替代风控系统做最终准入结论 |

## 输出裁剪

- 销售视角：摘要和业务信号优先，风险保持必要提示。
- 管理者视角：行业位置、客户价值、资源投入风险优先。
- 售前视角：业务模式、流程复杂度、系统现状线索优先。
- 客户成功视角：合作历史、经营压力、续费/扩容背景优先。
- 风控/签约视角：主体、股权、司法、经营异常、签约风险优先。

## 同一事实的角色化表达

示例事实：客户近期建设新生产基地。

| 角色 | 表达重点 |
|:---|:---|
| 一线销售 | 客户有扩张动作，说明近期业务重点可能集中在产能、区域覆盖和运营协同。 |
| 销售管理者 | 该扩张动作提升客户价值判断，但也需要结合资金压力、行业周期和项目落地情况判断投入优先级。 |
| 售前/解决方案 | 新基地建设可能带来跨区域组织、设备、流程和系统协同复杂度，需要关注公开资料中是否出现数字化、供应链、生产管理或服务交付线索。 |
| 客户成功/续费 | 如该客户已有合作记录，新基地可能影响扩容、服务覆盖和续费价值判断。 |
| 风控/签约 | 新基地建设可能带来资金和履约压力，应结合近两年被执行、处罚、税务和回款记录判断签约风险。 |
