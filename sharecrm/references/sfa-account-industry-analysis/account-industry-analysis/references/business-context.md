# 卖方上下文规则

本文定义 `account-industry-analysis` 如何读取卖方画像，并把行业变化与发问方业务相关性联系起来。

## 1. 卖方画像用途

卖方画像只用于内部推理，不用于正文展示。

用途包括：

- 判断哪些行业变化与发问方业务相关。
- 避免把与发问方无关的行业变化误写成重要信号。
- 帮助解释客户侧机会信号或风险信号。
- 支撑“该行业对发问方是否值得持续投入”的判断。该判断必须基于卖方服务形态和客户侧行业事实，不输出脱离发问方业务的泛行业结论。

## 2. 读取顺序

1. 优先读取已验证配置：`sharecrm sales get-config-by-key --data '{"key":"service_models"}'`。
2. 配置不足时，使用用户明确输入的卖方上下文。
3. 仍不足时，可用 CRM 产品/服务对象摘要、近 12-24 个月成交摘要做降级。
4. 三路都取不到时，标注卖方上下文缺失，但仍可输出客户行业事实。

配置 CLI 返回结构通常为：

```json
{
  "value": "<配置值>"
}
```

`value` 只进入 `meta.sellerContext.summaryForInternalReasoning`，不得在正文展示原值。配置读取是顶层命令，不属于 `crm-cli-map.md`。

## 3. 禁止展示

正文中不得直接展示：

- 卖方公司介绍。
- 卖方产品清单。
- 卖方能力说明。
- 配置原值。
- 内部成交敏感明细。

## 4. 允许输出

只允许输出客户侧相关性判断，例如：

- 行业监管加强可能放大该客户的合规建设需求。
- 行业竞争加剧可能放大该客户的降本和协同需求。
- 行业扩张可能带来组织复杂度和系统协同信号。

## 5. 不假设卖方行业

不得默认发问方是 SaaS、CRM 或企业服务厂商。
