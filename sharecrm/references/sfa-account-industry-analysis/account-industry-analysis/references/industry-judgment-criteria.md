# 行业判断口径

本文定义 `account-industry-analysis` 的通用行业判断底座。先定行业阶段，再按五个维度展开。

## 1. 行业阶段

行业阶段必须从以下枚举中选择一个主阶段：

- `增长`
- `稳定`
- `收缩`
- `转型`
- `监管加强`

如果证据同时指向多个方向，选择对目标客户影响最大的一个作为主阶段，其他因素在展开部分说明。

## 2. 五维判断

### 增长

关注：

- 市场规模和增速。
- 需求扩张或收缩。
- 需求结构是否变化。

落到客户：

- 该客户是处于扩张侧，还是承压侧。
- 行业增长或收缩是否改变该客户的需求方向。

### 监管

关注：

- 新政策。
- 合规要求。
- 准入门槛或补贴变化。

落到客户：

- 政策对该客户是利好、利空还是中性。
- 是否会拉长客户决策周期或形成刚性需求。

### 竞争

关注：

- 竞争格局。
- 集中度变化。
- 头部玩家动作。
- 替代品或新进入者。

落到客户：

- 该客户在行业中的位置。
- 是否面临价格战、替代风险或竞争加剧。

### 周期

关注：

- 行业景气位置。
- 上下游波动。
- 季节性或宏观挂钩。

落到客户：

- 该客户当前处于周期的哪一段。
- 行业周期如何传导到该客户经营、预算或项目节奏。

### 经营压力

关注：

- 成本压力。
- 毛利压力。
- 账期、库存、产能和资金压力。

落到客户：

- 哪类经营压力最可能作用于该客户。
- 是否构成与发问方业务相关的行业信号。

## 3. 行业是否值得做

当用户或上游编排需要判断“这个行业值不值得做”时，不做脱离发问方业务的泛行业判断，必须把行业事实与卖方画像交叉判断。

判断维度：

- 行业空间：市场规模、增速、政策支持、预算来源或长期需求是否存在。
- 客户可触达性：行业客户是否以项目制、大客户、渠道、区域经营、供应链协同或长期服务为主要经营方式。
- 卖方适配度：行业经营方式是否与 `service_models` 或 CRM 产品/服务摘要中的服务形态匹配。
- 进入壁垒：是否存在强供应商绑定、资质准入、头部垄断、低价竞争或长采购周期。
- 证据强度：判断来自公开行业事实、客户事实、CRM 内部样本还是模型推断。

输出枚举：

- `值得重点关注`
- `可验证后跟进`
- `谨慎观察`
- `暂不支持判断`

表达要求：

- 必须说明“为什么对发问方值得或不值得”，而不是只说行业朝阳或夕阳。
- 卖方画像不足时，只能输出 `暂不支持判断` 或 `待补卖方画像后判断`，不能强行给出投入结论。
- 该判断仍属于客户情报和行业适配判断，不输出资源投入计划、触达动作或销售节奏。

## 4. 事实与推断

- `事实`
  有可回链来源。
- `推断`
  基于行业规律或弱信号推理，必须显式标注。
- 无证据的内容不进结论。

## 5. 模板叠加

本文件只定义通用口径。命中行业模板时，必须在通用口径之上叠加模板的个性化判断点，不得只用通用规则。
