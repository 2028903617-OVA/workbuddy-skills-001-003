# 行业模板 Route 规则

本文定义如何根据目标客户的多维特征 route 到行业模板。

## 1. 不只看单一行业字段

route 前先综合判断：

- 经营模式
- 主营业务
- 规模分层
- 上下游位置
- 区域

## 2. 已建模板

当前已建的行业模板方向：

- 物流 / 供应链
- 制造 / 工业
- SaaS / 软件 / 信息技术服务
- 政府 / 事业单位 / 平台类主体

## 3. route 原则

- 命中模板时，必须读取对应模板。
- 子类判断不清时，优先使用模板通用部分，并把不确定内容放入待核实。
- 未命中模板时，走通用口径，并标注“该行业未建个性化模板”。
