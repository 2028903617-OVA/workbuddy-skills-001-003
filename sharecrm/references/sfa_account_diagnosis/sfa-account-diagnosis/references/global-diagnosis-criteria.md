# 客户经营洞察标准 — Global_Diagnosis_Criteria（knowhow）

用于形成客户经营洞察正文的统一判断框架。是诊断标准，不是对象事实；结论须落到客户数据、评分、销售记录或外部情报增强结果，并标注「事实 / 判断 / 待确认问题」。

本文件按 `output_template.md` 的输出章节顺序组织，已内聚原拆分文件中的客户真实关注点、组织突破口、增长空间、经营风险与经营动作诊断标准。后续生成客户诊断时优先读取本文件作为唯一标准入口。

## 0. 通用规则

### 评分信息的使用

- **有维度 / 特征原值**：用维度分解释强弱并标「判断」，但必须落回客户事实或销售记录。
- **仅有总分**：标注解释性不足，只做整体健康度判断，不输出高置信根因。
- **评分缺失**：先执行 `get_profile_score --objectApiName AccountObj`；CLI 失败或结果不可用时，再执行 `sfa-account-score` 获取正式 `Scoring_Result`。两者均不可用时不进入客户经营洞察。

### 来源分类

| 来源 | 包含 |
|:---|:---|
| CRM | 客户字段、联系人、销售记录、关联商机、成交状态等对象事实 |
| Scoring_Result | 首选 `get_profile_score` 或回退 `sfa-account-score` 生成的客户评分结果中的维度分、特征与依据；使用时记录实际来源 |
| 尽调增强 | `sfa-account-due-diligence-report` 结构化结果中的行业、业务、扩展空间等外部情报 |
| Knowhow | 本文件中的判断标准、风险规则、经营动作方法论 |
| AI 推断 | 基于上述事实与标准形成的解释性判断；不得写成 CRM 已证实事实 |

### 结论分级

- **高价值 / 高温经营**：价值高、关系热、机会活跃，且组织突破条件较好。
- **有空间 / 需经营**：有价值但关系、机会、关注点或组织突破条件存在短板。
- **风险 / 待激活**：长期无互动、关键人缺失、机会停滞或经营面临断档。

## 页头摘要

页头摘要只做概览，不拆「事实 / 判断 / 待确认问题」。必须压缩呈现：

- 客户名称、当前状态、负责人、客户级别。
- 评分总分、评分结论。
- 当前合作温度：根据关系温度、最近互动、在跑机会、经营风险综合判断，可输出 `高温 / 升温 / 低温 / 待激活 / 信息不足`。
- 本轮洞察主题：用一句话说明本次最重要的经营问题，如“机会活跃但关键人覆盖不足”。

## 一、客户当前状态

本章节回答“这个客户现在处于什么经营状态”。全局判断以选定评分来源返回的 `Scoring_Result` 为主骨架；评分优先使用 `get_profile_score --objectApiName AccountObj`，仅在 CLI 结果不可用时回退 `sfa-account-score`，并逐项结合客户事实、销售记录、关联商机与尽调增强结果。

| 评分维度（动态） | 判断要点 | 主要依据 | 输出要求 |
|:---|:---|:---|:---|
| 以选定 `Scoring_Result.dimension` 的业务含义为准 | 结合该维度评分与依据判断客户状态 | 评分依据、客户主数据、关联商机、联系人、销售记录、尽调增强 | 严格保留评分来源返回的名称、顺序和分数，不得套用固定维度 |

输出表格中的“事实 / 判断 / 待确认问题”必须分清：

- **事实**：CRM 或尽调中已经出现的信息。
- **判断**：基于评分与标准形成的解释。
- **待确认问题**：当前缺证据、影响后续经营的问题。

若评分结果仅有综合分而没有 `dimension`，只能输出整体健康度并标注解释性受限，不得自行拆分或补造客户价值、关系温度等维度。

## 二、客户真实关注点

本章节回答“客户真正关心什么，以及我方有没有打中”。重点不是复述客户说过什么，而是判断客户当前经营主题。

| 判断项 | 核心判断 | 常见来源 | 结论要求 |
|:---|:---|:---|:---|
| 表面关注点 | 客户公开表达的诉求、主题和高频议题 | 会议纪要、拜访记录、在跑商机主题、客户公开表述 | 写清客户现在在谈什么 |
| 深层驱动 | 客户推动当前合作或机会的真实原因 | 增长压力、管理提效、风险控制、合规要求、战略转型、领导关注 | 写清为什么这些关注点重要 |
| 当前约束 | 客户为什么没有更快推进 | 预算不明、关键人未覆盖、组织目标不一致、优先级不足、竞品影响 | 写清阻碍经营升温的关键约束 |
| 当前错位 | 我方表达与客户真实关注点之间的偏差 | 当前打法、内容触达、角色覆盖、价值主张 | 写清继续错位会带来的经营后果 |

生成要求：

- 每个判断项要有简短依据。
- 依据可以来自客户原话、销售记录高频主题、角色覆盖情况、缺失证据或行业背景。
- 结论要服务后续经营建议，不停留在抽象描述。
- 不把行业先验、尽调推测或 AI 推断写成 CRM 已证实事实。

## 三、组织突破口

本章节回答“从哪里打开局面最有效”。重点不是只看关系深不深，而是判断当前最可执行的组织与关系突破路径。

| 判断项 | 核心判断 | 输出要求 |
|:---|:---|:---|
| 当前入口条线 | 当前我方主要从业务、技术、采购、高层、生态或在跑商机哪条线进入客户 | 写清入口是否足够支撑经营目标 |
| 杠杆角色 | 是否存在可借力角色，如内部支持者、可引荐高层的人、主机会接口人 | 写清该角色能带来什么杠杆 |
| 拍板关键 | 最终影响经营、扩单或主机会推进的关键拍板角色是否清楚 | 不清楚时必须写“待确认” |
| 隐性阻力 | 单点关系依赖、关键人缺失、竞品绑定、内部目标不一致等阻力 | 写清阻力对经营的影响 |
| 推荐突破路径 | 下一步应沿业务线、技术线、高层关系、在跑商机反向带动等路径推进 | 必须是具体路径，不写“加强关系” |

生成要求：

- 每个判断都尽量给出依据。
- 不只写“关系一般 / 关系较好”，要明确“从哪里突破”。
- 若只触达接口人，不算形成有效突破基础。

## 四、增长空间

本章节回答“这个客户后续还有没有做大的空间”。不得把潜在想象空间直接当成真实增长空间。

| 判断项 | 核心判断 | 输出要求 |
|:---|:---|:---|
| 当前主机会 | 当前最值得经营的主线是什么，可以是明确在跑商机，也可以是正在升温的重点方向 | 写清主机会的现实依据 |
| 潜在扩展方向 | 除当前主机会外可延伸的部门、场景、产品、区域、条线 | 只输出有事实或尽调增强支撑的方向 |
| 复制可能性 | 当前成功路径能否在客户内部复制 | 看组织基础、业务共性、关键角色支持 |
| 战略合作空间 | 是否存在更长期、跨部门或生态级合作可能 | 无证据时写“暂不明确” |
| 是否值得追加投入 | 综合价值、关系温度、机会活跃度和增长空间判断 | 结论限定为 `值得重投入 / 值得选择性投入 / 暂不追加投入` |

高投入建议必须与可验证增长空间挂钩，不能只因为客户名气大或想象空间大就建议重投入。

## 五、经营建议

本章节先输出经营策略，再给关键动作。动作必须承接前面客户当前状态、真实关注点、组织突破口、增长空间与风险提示。

### 经营状态 → 目标 → 动作

| 状态 | 经营目标 | 未达标项 | 建议动作 | 优先级 |
|:---|:---|:---|:---|:---:|
| 破冰 / 初建关系 | 建立基础信任，识别关键人与首个业务机会 | 关键人未识别 | 梳理客户组织架构，锁定决策人 / 影响者 | 高 |
| 破冰 / 初建关系 | 启动转化 | 无在跑商机 | 基于客户业务场景挖掘首个商机并建档 | 高 |
| 升温 / 深耕 | 扩大覆盖，提升客单与复购 | 关系单点 | 横向拓展多部门关系，降低单点依赖 | 中 |
| 升温 / 深耕 | 盘活管道 | 商机停滞 | 对停滞商机逐个复盘卡点并制定推进计划 | 高 |
| 扩展 / 防守 | 保持活跃、防流失、挖掘增购 | 长期无互动 | 安排定期价值回访，带新方案 / 案例 | 高 |
| 扩展 / 防守 | 防守关键阵地 | 竞品介入信号 | 强化已认可价值点，巩固关键人支持 | 高 |

### 降级策略

- 活跃状态线索缺失：先建议补齐当前经营状态判断，再给基于现状的保守动作。
- 证据不足：优先建议补齐关键信息（关键人、在跑机会、客户关注点），而非高置信推进。

### 动作生成要求

- 每条建议必须写清：动作、目的、预期解决的问题、负责人 / 对象、节奏。
- 禁止空泛表达：`继续跟进`、`加强沟通`、`保持联系`、`持续推动`。
- 动作要回溯到至少一个前文短板或风险。

## 附：经营风险提示

风险识别聚焦当前最影响客户经营质量、关系温度、机会活跃度与后续拓展的关键风险，并给出优先级、来源、影响与优先化解方向。

### 风险来源

- 全局判断中的明显短板，如客户价值、关系温度、机会活跃度、组织突破条件、经营风险。
- 当前经营状态对应的未达标项。
- 客户对象特有风险。
- 通用销售管理风险。

### 风险优先级

- **P0**：不处理会导致客户流失、关键机会断档，或长期无法进入有效经营状态。
- **P1**：会显著削弱客户关系、拖慢经营推进、降低后续扩单与复购机会。
- **P2**：需要关注，但短期不直接阻断经营推进。

### 客户经营特有风险映射

| 优先级 | 常见触发 | 优先化解方向 |
|:---:|:---|:---|
| P0 | 长期无有效互动，客户活跃度明显下滑 | 发起价值回访并恢复周期性互动 |
| P0 | 关键关系人缺失或只依赖单点关系 | 梳理关键人地图，补齐决策人 / 影响者覆盖 |
| P0 | 客户名下在跑机会集体停滞 | 盘点在跑机会卡点，逐个制定盘活动作 |
| P1 | 有价值但缺少明确增购或深耕路径 | 设计价值回访或增购切入点 |
| P1 | 竞品介入、客户价值感弱化 | 巩固关键人支持并重建价值差异 |
| P2 | 下一阶段经营目标不清晰 | 明确本季度经营目标与对应触达计划 |
| P2 | 客户画像不完整 | 补齐关键背景信息并持续监测 |

### 风险措辞模板

每条风险建议保持以下表达结构：

- **风险点**：使用具体经营缺口描述，如“客户关系过度依赖单一接口人”。
- **来源**：标明来自当前状态判断、经营未达标或经营风险。
- **影响**：明确说明对客户经营、商机转化或关系健康度的影响。
- **化解方向**：给出最优先的经营动作方向。
