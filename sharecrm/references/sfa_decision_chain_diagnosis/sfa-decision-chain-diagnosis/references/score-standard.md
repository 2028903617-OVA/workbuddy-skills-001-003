# 决策链诊断评分标准

## 适用范围

本文件只适用于 `NewOpportunityObj` 的决策链诊断场景。

若用户本次明确提供额外诊断依据，可作为补充证据使用；但不得替代 CRM 中已查询到的商机事实。

## 评分模型

### 三底线定义

| 维度 | 定义 |
|:---|:---|
| 决策者覆盖 | 是否真正覆盖了有预算权、拍板权、关键影响力的人 |
| Coach经营深度 | 是否拥有愿意传递内部信息、推动引荐、关键时刻站队的人 |
| 反对者识别 | 是否知道谁在反对、为什么反对、反对强度如何，以及是否有应对策略 |

### 计分口径

- 评分维度固定为三项：决策者覆盖、Coach经营深度、反对者识别。
- 每个维度按 `0-10` 分评分。
- 综合评分为三项相加，总分 `0-30`。
- 不得因字段不可见、证据不足或关系对象缺失而缩小分母。

```text
综合评分 = 决策者覆盖 + Coach经营深度 + 反对者识别
```

### 健康等级

| 分数区间 | 等级 | 说明 |
|:---:|:---:|:---|
| 25-30 | 优秀 | 决策链结构完整，具备较强推进条件 |
| 18-24 | 及格 | 存在关键缺口，但仍具备推进基础 |
| 12-17 | 危险 | 决策链存在明显短板，推进高度依赖补洞 |
| 0-11 | 极危 | 决策链基础薄弱，短期内高概率卡死或失控 |

## 使用规则

### 通用原则

1. 必须优先使用 CRM 事实，其次使用用户明确补充的项目事实。
2. 不得把职位头衔直接等同于真实决策权、支持度、影响力或站队态度。
3. 缺失证据不能视为正向证据；证据不足时必须保守给分。
4. 所有结论都要尽量附带证据说明；无法证实时使用 `待补充` 或 `无法判断`。
5. 推断性结论必须标记 `⚠️ 推断`。
6. `诊断人` 无法从 CRM owner、当前上下文或用户输入确认时，输出 `待补充`。
7. 诊断方法论只能作为分析框架，不能当作项目事实直接输出。

### 稀疏证据处理

- `ContactObj`、关系对象或销售记录不足时，不得凭职位、经验或行业常识补齐人力地图。
- 无法确认最终拍板者时，决策者覆盖不得给高分。
- 无法确认有人愿意传递内幕、引荐高层或主动站队时，Coach经营深度不得给高分。
- 无法确认不存在反对者时，反对者识别不得按“无风险”处理。
- 若某一维度几乎无证据，优先给 `0-3` 分，并在说明中写明缺口原因。
- 若存在部分证据但仍无法闭环，优先给 `4-6` 分，并明确列出仍需补充的信息。

## 维度评分

为避免表述松散，三个维度统一按“核心判断—关键证据—评分区间与标准—低分信号”进行整理。评分时应优先看是否有**被事实验证的证据**，再决定分值区间；不能因为描述听起来合理就给高分。

### 1. 决策者覆盖

**核心判断**

是否真正覆盖了有预算权、拍板权、关键影响力的人，而不是只覆盖接口人或中间协调人。

**关键证据**

| 证据项 | 关注点 |
|:---|:---|
| 最终拍板者 | 身份是否明确 |
| 决策路径 | 签字层级、汇报路径是否清楚 |
| 关键角色覆盖 | 是否已接触高层 / 业务方关键人 / IT关键人 / 采购关键人 |
| 关系深度 | 当前最深关系人是否只是项目接口人 |
| 行为信号 | 销售记录中是否出现引荐、汇报、评审或拍板信号 |

**评分区间与标准**

| 分值区间 | 评分标准 |
|:---:|:---|
| 8-10 | 最终拍板者较明确，关键决策角色覆盖较完整，且有真实接触或验证证据。 |
| 5-7 | 已识别部分关键角色，但最终拍板链条仍有缺口，或高层覆盖未被充分验证。 |
| 2-4 | 只覆盖接口人或局部角色，对谁拍板、谁影响拍板仍缺少可靠证据。 |
| 0-1 | 无法确认任何真实决策者，或现有认知高度可能误判。 |

**低分信号**

- 只知道对接人，不知道谁拍板。
- 把采购、IT负责人、接口人直接当成最高决策者。
- 没有高层覆盖，或高层覆盖完全依赖猜测。

### 2. Coach经营深度

**核心判断**

是否拥有愿意传递内部信息、推动引荐、关键时刻站队的人，而不只是普通配合联系人。

**关键证据**

| 证据项 | 关注点 |
|:---|:---|
| 内部信息 | 是否有人提供非公开内部信息 |
| 引荐能力 | 是否有人愿意引荐更高层或关键决策者 |
| 推动动作 | 是否有人在关键节点主动推动项目 |
| 实际影响 | 是否能看到该人对内部意见、采购、评审的实际影响 |
| 事实验证 | 该关系是否已被销售记录或用户明确事实验证 |

**评分区间与标准**

| 分值区间 | 评分标准 |
|:---:|:---|
| 8-10 | 存在较明确的 Coach，且能提供内幕、推动引荐、关键时刻愿意站队。 |
| 5-7 | 存在积极联系人，但其影响力、稳定性或站队强度尚未完全验证。 |
| 2-4 | 只有常规配合联系人，没有证据证明其具备真实 Coach 能力。 |
| 0-1 | 没有可识别 Coach，或所谓 Coach 仅为主观猜测。 |

**低分信号**

- 联系人愿意配合，但从未提供关键内部信息。
- 没有 upward 引荐动作。
- 把响应快、态度好误判为 Coach。

### 3. 反对者识别

**核心判断**

是否识别出谁在反对、为什么反对、反对强度如何，以及是否具备对应化解思路。

**关键证据**

| 证据项 | 关注点 |
|:---|:---|
| 反对者身份 | 是否识别到明确反对者或潜在阻力方 |
| 反对原因 | 是否知道其反对原因（预算、风险、竞品、技术、流程、组织利益等） |
| 影响强度 | 是否知道其影响范围和否决强度 |
| 应对策略 | 是否已有对应化解动作或绕行路径 |
| 风险线索 | 是否能从销售记录中看到竞品介入、内部阻力、评审异议等线索 |

**评分区间与标准**

| 分值区间 | 评分标准 |
|:---:|:---|
| 8-10 | 反对者身份、原因、强度和应对策略都较清晰。 |
| 5-7 | 已识别部分阻力或潜在反对者，但动机或强度仍有缺口。 |
| 2-4 | 仅模糊感觉项目受阻，不清楚是谁反对、为何反对。 |
| 0-1 | 直接认为“没有反对者”，但实际上只是因为缺少证据。 |

**低分信号**

- 把“暂未记录到反对者”当作“没有反对者”。
- 已明显卡点，但没有任何阻力归因。
- 只知道有竞品，不知道竞品影响了谁。


## 诊断辅助框架

以下内容用于辅助判断三底线，但不是独立打分项。

### 真假决策者判断

**作用**：帮助校准“决策者覆盖”是否真的覆盖到了真实拍板者，而不是只覆盖流程角色或接口角色。

**交叉验证维度**

- 采购流程
- 评标过程
- 历史决策
- 最高层覆盖

**常见假决策者**

- 采购负责人
- IT负责人
- 项目接口人
- 部门负责人

### 隐性权力中心识别

**作用**：帮助识别组织架构图之外、但实际强影响结果的人，辅助判断真实阻力与真实影响力来源。

**重点识别**

- 总裁助理
- 沉默话语权
- 左右手
- IT侧红线

### 人力地图六类角色

**作用**：帮助结构化检查关键角色是否覆盖完整，避免只盯单一接口人。

- Sponsor
- 最高决策者
- 业务方KP
- IT方KP
- 采购方
- 项目接口人

## 评分示例

### 示例一：证据充分的高质量诊断

**已知事实**

- 已确认最高决策者为集团副总裁，销售记录显示已完成汇报。
- 业务方负责人愿意引荐采购负责人，并多次同步内部预算状态。
- IT负责人对安全改造有顾虑，但原因、影响点和化解动作已被明确记录。

**推荐评分**

- 决策者覆盖：`9/10`
- Coach经营深度：`8/10`
- 反对者识别：`8/10`
- 综合评分：`25/30`
- 健康等级：`优秀`

**说明示例**

- 决策者覆盖高，是因为最终拍板者明确，且已存在真实高层接触记录。
- Coach经营深度高，是因为业务方负责人不仅态度积极，还能提供预算信息并推动关键引荐。
- 反对者识别高，是因为 IT 侧阻力已被识别，且有具体应对动作，而不是泛泛而谈。

### 示例二：证据稀疏的保守评分

**已知事实**

- 只知道项目接口人和一名 IT 联系人。
- 没有明确记录谁拍板、谁影响拍板。
- 没有证据表明现有联系人能提供内部信息或引荐更高层。
- 项目推进变慢，但没有明确记录具体反对者。

**推荐评分**

- 决策者覆盖：`3/10`
- Coach经营深度：`2/10`
- 反对者识别：`3/10`
- 综合评分：`8/30`
- 健康等级：`极危`

**说明示例**

- 决策者覆盖低，是因为当前只接触接口层，无法确认真实拍板链条。
- Coach经营深度低，是因为现有联系人虽有配合，但没有证据支持其具备 Coach 能力。
- 反对者识别低，是因为项目已变慢却没有任何明确阻力画像，不能把“未知”写成“无反对者”。

### 示例三：真假决策者误判场景

**已知事实**

- 团队一直把采购负责人当作最终决策者。
- 但销售记录显示，历史类似项目最终由业务副总拍板，采购只负责流程推动。
- 现阶段尚未覆盖业务副总，也没有人能引荐。

**推荐评分**

- 决策者覆盖：`2/10`
- Coach经营深度：`1/10`
- 反对者识别：`5/10`
- 综合评分：`8/30`
- 健康等级：`极危`

**说明示例**

- 决策者覆盖极低，因为当前核心误判在于把流程角色当成拍板角色。
- Coach经营深度极低，因为没有任何人能帮助跨到真实拍板层。
- 反对者识别可给中低分，是因为虽然未必有明确反对者，但至少已识别出组织路径上的关键阻力点。
