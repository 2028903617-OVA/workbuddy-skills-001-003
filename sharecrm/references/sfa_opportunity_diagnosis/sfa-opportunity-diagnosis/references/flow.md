# 商机诊断流程

本文件负责流程编排与内部分析视角。对象边界、评分来源优先级、评分驱动诊断、风险分级、Markdown 输出等硬约束由 `SKILL.md` 定义，本文件不放宽。

## 内部分析视角

三个连续视角，非互斥、不三选一，默认按序执行：

1. **视角A 洞察诊断**：以首选 CLI 或回退评分 skill 产出的 `Scoring_Result` 维度结果为主骨架，形成整体判断与完整输出骨架。
2. **视角B 商机画像**：收敛身份、背景、核心短板与主要风险，强化概要、全局诊断、风险识别的可读性。
3. **视角C 下一步推进**：把已识别短板转成赢单策略与行动建议，明确“下一步怎么跟”。

## 执行步骤

1. 读取 `references/global-diagnosis-criteria.md`（含证据等级标注规则）。
2. 先执行 `sharecrm sales profile get_profile_score --objectApiName NewOpportunityObj --objectId <opportunity_id>` 获取当前商机评分。若返回同一商机的非空评分信息，直接作为 `Scoring_Result`；若调用失败、结果为空、无评分信息或对象不一致，调用 `sfa-opportunity-score` 对同一商机评分并使用其输出。视角A结合所选 `Scoring_Result`、`AI_Stage`、商机事实与销售记录形成全局诊断；全局诊断维度必须使用所选评分来源的名称和顺序，每个维度的评分依据须标注「来源」。
3. 视角B：收敛商机画像（当前状态、关键背景、核心短板、主要风险）。
4. 从全局短板、阶段不达标项与销售管理风险中识别 `P0 / P1 / P2` 风险。
5. 视角C：基于真实阶段和全局真实数据，综合分析和推理，诊断真实性和真问题，生成赢单策略与行动建议。
6. 读取 `references/output_template.md`，按其固定章节结构顺序输出。
