# WorkBuddy 实操指南（踩坑速查 + 操作规范）

> 覆盖两个实战任务的真实踩坑，共 **53 条**。
> **用法**：开工前读「§1 铁律」；遇到具体故障查「§3 速查总表」，按编号和「在哪一节」跳 `references/` 看详情；交付前读「§4 验收清单」。

## §0 开工前先看这两条

1. **本机专用文件要摘除**：`references/00-my-machine.md` 记的是**这台机器**的路径、性能档位、排程时刻。对外分享这个 skill、或同步到别的机器之前，**先删掉它**——照搬会做反。
2. **对外文件先跑脱敏自检**：直接传**文件或目录**给 `scripts/scan_secrets.py`（Office 会自动取真文本）。看到"未取到文本"的报警必须人工确认，**不能当成已检查**。

## §1 十条铁律（最高优先级，违反必翻车）

| # | 铁律 | 一句话原因 |
|---|---|---|
| **F1** | **绝不并行 Edit 同一文件** | Edit 是"读→改→写"，同消息多次并行会互相覆盖，**静默丢失且无报错** |
| **F2** | **内容含反引号/特殊字符时，绝不走 shell** | bash 会做命令替换，把 `` `SomeApiName` `` 这类内容直接吞掉 |
| **F3** | **生成的文件必须回读实际产出再交付** | 凭记忆汇报必然出错；docx 用文本 dump，xlsx 用脚本读回 |
| **F4** | **版本迭代另存新名，并显式声明哪一版是最终版** | 同名多版必然误发；`_v2` `_v3` 递增，禁用覆盖 |
| **F5** | **写盘前探测占用，占用则另存** | Office/预览面板锁句柄 → `PermissionError`；不中断，改 `_v2` |
| **F6** | **对外文件先跑脱敏自检，且必须看上下文** | 命中词常在"本件不含…"免责句里，只数词频会误判 |
| **F7** | **读外部导出的 Excel 一律 `read_only=False`** | 导出文件尺寸信息不规范，只读模式会只读到 0~1 行/列 |
| **F8** | **跨机任务第一步先硬件取证确认本机是哪台** | hostname/用户名不可信，猜反则路径、排程、同步全盘做反 |
| **F9** | **不做推测性决策**（样式、口径、命名） | 用户手调版才是权威；口径不明就问，不猜 |
| **F10** | **口径变更要显式收回上一版说法** | 静默改会让用户拿旧说法对新文档，判断依据失效 |

## §2 环境基线（模板 · 按你的机器填写）

- **Python / Node**：用你环境的绝对路径（虚拟环境里含 openpyxl / python-docx 的那个）
- **Bash shim 不可用命令**：`rm` `dirname` `cd` `head` `tail` `grep` `ls` → 一律改 Python（报 `command not found` / Exit 127）
- **Glob 可能不认某些盘符** → 用 Python `os.listdir` 写临时文件再 Read
- **Read 单行超长会截断** → 长文本先切分
- **PowerShell 可能不回显 stdout** → 取信息走 Python

以上各项的真实值记到 `references/00-my-machine.md`，正文不写死任何具体机器的信息。

## §4 交付前验收清单（可执行条目）

- [ ] **V1** 产出文件已回读，内容与需求逐条一致（非凭记忆）
- [ ] **V2** 多版本文件中已明确告知"哪一版是最终版"
- [ ] **V3** 对外文件跑过 `scripts/scan_secrets.py` 且人工看过命中上下文
- [ ] **V4** xlsx 按列检查 number_format 统一；重排行后按行类型刷过样式
- [ ] **V5** docx 用文本 dump 核对章节齐全、无占位符残留
- [ ] **V6** 术语全文档统一，扫旧词零残留
- [ ] **V7** 涉口径变更处，已写明"上一版说法作废"
- [ ] **V8** 跨机任务已确认本机身份（硬件锚点）

**怎么判"不适用"**：本次交付**根本没产生该形态的产物**才算不适用（例：没做 xlsx 则 V4 不适用；没做 docx 则 V5 不适用；首版无旧口径则 V7 不适用）。
以下情况**不算**不适用，必须实做：文件已生成但没回读（V1 不达标）、对外发但没扫（V3 不达标）、有多个版本但没声明（V2 不达标）。
报告时逐条写「达标 / 不达标 / 不适用（原因）」。

**V4 的可执行校验片段**：

```python
from collections import Counter
import openpyxl

wb = openpyxl.load_workbook(p, read_only=False)      # ★ 不用 read_only
ws = wb['明细']
# 1) 数字格式是否统一
print(Counter(c.number_format for c in ws['D'][1:]))
# 2) 回读实际值（不凭记忆）
for r in ws.iter_rows(min_row=1, max_row=5, values_only=True):
    print(r)
# 3) 样式整体比较（theme 色取 .rgb 会报错）
a, b = ws['A1'], ws['A2']
print(str(a.fill) == str(b.fill))
```
