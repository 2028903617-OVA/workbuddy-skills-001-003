# 00 本机速查（本机专用）

> 本文件只记录**这台机器**的环境与排程，通用正文里不写这些。
> **对外分享 skill、或同步到别的机器之前，先删掉本文件**——里面的路径、性能档位、排程时刻只对这台机器成立，照搬会做反。
> 换机器请按下面 0.1 的取证命令重新测，不要凭印象填（F8 / E09）。

## 0.1 硬件锚点（跨机任务第一步必查）

```cmd
hostname
wmic baseboard get Manufacturer,Product
wmic cpu get Name
wmic os get Version
```

把输出固化下来，以后每次跨机任务**先比对、全部吻合才继续**。hostname / 用户名 / device-id 都是不可信随机值，机器编号只是自贴标签，系统并不知道。
