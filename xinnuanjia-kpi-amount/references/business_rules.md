### 目标表

目标表包含所有人员的目标，试用期人员可能有多行，需按报表月份选择：

- `（7月试用期）`: 仅 7 月生效
- `（8-12月）`: 8-12 月生效
- `（7.8月试用期）`: 7-8 月生效
- `（9-12月）`: 9-12 月生效
- `（设计师）` 或无说明：全年生效

### 输出表（25 列）

在基础表 23 列的基础上，增加 `达成奖金` 列，并将奖金列拆分为独立的 5 列：

1. 月度整体达成奖金
2. 第一成交达成奖金
3. ABC成交达成奖金
4. ABC成交顾客数达成奖金
5. ABC录入线索达成奖金

## 奖金计算规则

每项指标达成率 ≥ 1 时获得 300 元奖金：

- `b4` = 300 if 月度整体达成率 ≥ 1 else 0
- `b1` = 300 if 第一成交率金额达成率 ≥ 1 else 0
- `b3a` = 300 if ABC成交金额达成率 ≥ 1 else 0
- `b3c` = 300 if ABC成交顾客数达成率 ≥ 1 else 0
- `b2` = 300 if ABC线索新建达成率 ≥ 1 else 0

个人达成奖金 = b4 + b1 + max(b3a, b3c) + b2

> 注：ABC 成交金额奖金与 ABC 成交顾客数奖金不叠加，取两者中较高者。

停用人员（姓名含"停用"）所有奖金为 0。

## 公式规则

### 达成率列

所有达成率均写为公式，基于 `目标表` 的目标值自动计算：

- `F 列（月度整体达成率）`：`=IF(D{row}=0,0,E{row}/D{row})`
- `J 列（第一成交率金额达成率）`：`=IF(H{row}=0,0,I{row}/H{row})`
- `N 列（ABC成交金额达成率）`：`=IF(L{row}=0,0,M{row}/L{row})`
- `T 列（ABC成交顾客数达成率）`：`=IF(R{row}=0,0,S{row}/R{row})`
- `X 列（ABC线索新建达成率）`：`=IF(V{row}=0,0,W{row}/V{row})`

### 人员行

- 奖金列：`=IF(达成率列>=1,300,0)`
- 达成奖金：`=G{row}+K{row}+Y{row}+IF((O{row}+U{row})>=300,300,0)`

### 小计行（门店 / 渠道 / 美的特渠部）

- 月度整体达成奖金：`=IF(F{row}>=1,2000,0)`
- 第一成交达成奖金 / ABC成交达成奖金 / ABC成交顾客数达成奖金 / ABC录入线索达成奖金：`=IF(对应达成率列>=1,1000,0)`
- 达成奖金：`=G{row}+K{row}+Y{row}+IF((O{row}+U{row})>=1000,1000,0)`

小计行的奖金按小计自身的达成率计算，不再简单相加组内人员奖金。

## 数字格式

- 金额 / 奖金 / 客单价 / 销售指标列：强制 `#,##0.00`（保留 2 位小数）。
- 客户数 / 顾客数 / 线索数列：强制 `0`（整数）。
- 达成率列：保持模板原百分比格式。
