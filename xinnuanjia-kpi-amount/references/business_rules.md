## 二、奖金规则

### 2.1 人员行（每项 300 元）

```
b4  = 300 if 月度整体达成率 >= 1 else 0
b1  = 300 if 第一成交率金额达成率 >= 1 else 0
b3a = 300 if ABC成交金额达成率 >= 1 else 0
b3c = 300 if ABC成交顾客数达成率 >= 1 else 0
b2  = 300 if ABC线索新建达成率 >= 1 else 0

个人达成奖金 = b4 + b1 + max(b3a, b3c) + b2      # 上限 1200
```

> ABC 成交金额奖金与 ABC 成交顾客数奖金**不叠加**，取较高者。
> 停用人员（姓名含 `停用`）五项全 0，且目标不参与解析。

### 2.2 小计行

```
b4  = 2000 if 小计月度整体达成率 >= 1 else 0
b1  = 1000 if 小计第一成交达成率 >= 1 else 0
b3a = 1000 if 小计ABC成交金额达成率 >= 1 else 0
b3c = 1000 if 小计ABC成交顾客数达成率 >= 1 else 0
b2  = 1000 if 小计线索达成率 >= 1 else 0

小计达成奖金 = b4 + b1 + b2 + (1000 if b3a + b3c >= 1000 else 0)   # 上限 5000
```

小计行按小计自身达成率计算，**不是**组内人员奖金相加。

## 三、部门结构

### 3.1 自动推导（v2 核心）

按基础表二级部门**首次出现顺序**推导块顺序 → 应用 `alias` 别名 → 剔除 `skip_depts` → `parent_blocks` 中的父块展开为子块候选，**父块本身排到最后**（只出汇总小计，不出人员）。

2026-09 实际推导结果：

```
美的滨江店 → 东芝华东店 → 天猫彩电部 → 东芝宝龙店 → 特定渠道1部 → 特定渠道2部 → (美的特渠部 汇总)
```

### 3.2 人员归部覆盖（`person_dept`）

父部门 `美的特渠部` 在基础表里是**一整块**，必须人工拆到 1部/2部，否则 `assign()` 报错（禁止猜）：

| 部门 | 人员 |
|---|---|
| 特定渠道1部 | 吴建、车邦建、韩芬、周晨烨 |
| 特定渠道2部 | 王浩萍、郁轹文、钟俊楠、陈学健 |

`person_dept` 也用于**跨部门还原**：2026-09 钟俊楠在基础表里挂在天猫零售部，按用户口径还原到特定渠道2部。

### 3.3 小计行标签（`sub_label`）

| 块 | 标签 |
|---|---|
| 门店类（美的滨江店 / 东芝华东店 / 天猫彩电部 / 东芝宝龙店） | `XX合计` |
| 特定渠道1部 | `渠道1部小计` |
| 特定渠道2部 | `渠道2部小计` |
| 美的特渠部 | `渠道部合计` |

## 四、小计目标口径（★ 两版本并存，务必看这里）

## 五、公式规则

### 5.1 达成率列（全部写公式）

| 列 | 公式 |
|---|---|
| F 月度整体达成率 | `=IF(D{r}=0,0,E{r}/D{r})` |
| J 第一成交率金额达成率 | `=IF(H{r}=0,0,I{r}/H{r})` |
| N ABC成交金额达成率 | `=IF(L{r}=0,0,M{r}/L{r})` |
| T ABC成交顾客数达成率 | `=IF(R{r}=0,0,S{r}/R{r})` |
| X ABC线索新建达成率 | `=IF(V{r}=0,0,W{r}/V{r})` |

### 5.2 奖金列（人员行 thr=300，小计行 base=2000 / thr=1000）

| 列 | 公式 |
|---|---|
| G 月度整体达成奖金 | `=IF(F{r}>=1,{base},0)` |
| K 第一成交达成奖金 | `=IF(J{r}>=1,{thr},0)` |
| O ABC成交达成奖金 | `=IF(N{r}>=1,{thr},0)` |
| U ABC成交顾客数达成奖金 | `=IF(T{r}>=1,{thr},0)` |
| Y 线索达成奖金 | `=IF(X{r}>=1,{thr},0)` |
| C 达成奖金 | `=G{r}+K{r}+Y{r}+IF((O{r}+U{r})>={thr},{thr},0)` |

小计行：`base=2000`，`thr=1000`；人员行：`base=300`，`thr=300`。

| 项 | v1 | v2 |

| 部门块顺序 | 写死 `美的滨江店 → 东芝华东店 → 东芝宝龙店 → 渠道1 → 渠道2 → 特渠部` | 按基础表首次出现顺序 + 父块排最后 |

| CLI | 4 个位置参数 | 15 个具名参数 |

## 八、已知边界

1. **`--month` 越界会静默算错**（所有 period 不命中 → 全回落报表指标）→ v2 已加 1–12 校验。
2. **基础表新增部门** → 必须 `--dept` 确认或 `--skip-dept` 跳过，不吃默认值。
3. **本地无 Office 计算引擎** → 交付前用独立复算（读产物静态列重算）+ 与上期成品逐格比对替代公式引擎校验。
4. **`人员表` 合并按第 1 列当键**（人员导出的「唯一性ID」），前提是导出格式不变；若列顺序变了要改 `replace_personnel()`。
